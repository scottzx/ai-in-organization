## 排版预览版

[查看最新排版预览版](企业数智化转型研究报告-排版预览版.pdf)，共332页，基于2026年10月16日源稿，上册为初稿v9.0，下册为初稿v8.0。下册62篇案例统一采用七节结构，保留101个场景的阶段、锚点与来源；第二至第五章分别展开MTL、LTC、IPD、ITR，第二章保留16张配图；第六章围绕四条流程共同判断、安排资源与采用反馈展开智力飞轮，将决策快、试错快、复制快和切换快落到组织工作，第七章为实施建议。

正文按小四（12磅），固定行距28磅，段前、段后均为0磅，首行缩进两个汉字并两端对齐。一级标题三号（16磅），二级标题小三（15磅），三级标题四号（14磅），四级标题小四（12磅）；标题同样为28磅行距、段前后0磅。表格统一用五号（10.5磅）、17磅行距，表头和图表标题用五号黑体加粗，来源注释用9磅字体、16磅行距。

正文强调文字采用纯黑色黑体；项目符号与编号条目的首行同样缩进两个汉字（24磅）。配图及链接采用蓝色主调（#1D4ED8），表头改用稍浅的蓝底（#3D73C6）配白字；表格隔行底色与配图卡片使用浅蓝，图中文字和辅助线使用深蓝、灰蓝。

表格和图表段前、段后均为6磅。70张表格统一在上方显示加粗表题，跨页重复表题和表头；表题名称维护在[表题清单](../../scripts/pdf-table-captions.json)。16张插图与1张知识网络流程图的图题统一放在下方居中，并随图整体分页。PDF渲染时把插图内原来的主标题移到外部图题，避免重复，原始可编辑图稿仍可独立使用。

本轮构建正文使用AR PL UMing，一级标题与强调文字使用文泉驿正黑，二级标题使用Noto Serif SC；字体路径与TTC索引记录在构建清单。16张MTL配图的PNG与SVG四周统一保留16px留白，图中文字使用文泉驿正黑，并按标题、正文与辅助标签固定字号和字重。生成及检查方法见[MTL配图维护说明](../illustrations/chapter-2-mtl/README.md)。

封面单独设置字号；目录列出上册章、节以及下册行业、案例。页眉左侧为报告名，右侧为当前章节，页脚居中显示页码。封面无页眉页脚，前置页使用罗马页码，正文从导论第1页连续编排。原有16张插图、目录跳转、书签、正文引用与来源链接均保留。

复现本预览版：

```bash
python3 scripts/build-pdf.py --output output/pdf/企业数智化转型研究报告-排版预览版.pdf
```

[预览版构建清单](企业数智化转型研究报告-排版预览版.manifest.json)保存字体、字号、正文起页、物理页与显示页码、表题、图题、源文件校验值及内容检查结果。已检查5,109个正文片段、615个图中文字片段和87个图表标题，无缺失或正文空白页；已渲染抽查新版智力飞轮的章首、四项核心职能表与组织协同检验表，并扫描全书文字边界。

## 后续更新

先修改原有Markdown正文，再运行[生成脚本](../../scripts/build-pdf.py)：

```bash
python3 scripts/build-pdf.py
python3 scripts/build-pdf.py --chapter 上册-研究报告/02-最小执行单位-从人到任务.md
python3 scripts/validate.py
```

需要Pandoc、Python包`reportlab`及`pypdf`。生成器采用上述预览版排版，默认寻找本机WPS的仿宋、macOS的黑体与楷体；本轮云环境构建通过环境变量指定前述可用中文字体。其他环境可通过`BOOK_BODY_FONT`、`BOOK_HEADING_FONT`、`BOOK_KAI_FONT`、`BOOK_DIAGRAM_FONT`与`BOOK_DIAGRAM_HEADING_FONT`指定覆盖中文的TrueType字体路径。页码自动编排，后续版本页数变化时同步本说明。

脚本读取93份源文档，保留正文、表格及来源信息，省去网页导航与逐篇重复的版本行，将附录D的Mermaid流程图绘制为矢量图。第二章图片优先读取同名SVG，保留矢量清晰度及可检索文字。生成后检查5,109个正文可见文本片段和615个图内文本片段是否完整、是否存在正文空白页及失效的内部跳转；跨页表格按整行换页并重复表头。

[构建清单](build-manifest.json)记录每份源文档的SHA256、章节起始页、PDF校验值及完整性检查结果。重新生成后须渲染PDF，检查封面、目录、章节转折、长表格与流程图。内容检查和排版检查各自保留。
