## 排版预览版

[查看排版预览版](企业数智化转型研究报告-排版预览版.pdf)，共279页，供本轮审阅整体效果；原发行合订本保留。

正文采用仿宋小四（12磅），固定行距28磅，段前、段后均为0磅，首行缩进两个汉字并两端对齐。一级标题黑体三号（16磅），二级标题楷体小三（15磅），三级标题仿宋四号（14磅），四级标题仿宋小四（12磅）；标题同样为28磅行距、段前后0磅。表格统一用五号（10.5磅）、17磅行距，表头和图表标题用五号黑体加粗，来源注释用9磅字体、16磅行距。

正文强调文字采用纯黑色黑体；项目符号与编号条目的首行同样缩进两个汉字（24磅）。配图及链接采用蓝色主调（#1D4ED8），表头改用稍浅的蓝底（#3D73C6）配白字；表格隔行底色与配图卡片使用浅蓝，图中文字和辅助线使用深蓝、灰蓝。

表格和图表段前、段后均为6磅。67张表格统一在上方显示加粗表题，跨页重复表题和表头；表题名称维护在[表题清单](../../scripts/pdf-table-captions.json)。16张插图与1张知识网络流程图的图题统一放在下方居中，并随图整体分页。PDF渲染时把插图内原来的主标题移到外部图题，避免重复，原始可编辑图稿仍可独立使用。

16张配图的PNG与SVG四周统一保留16px留白，文字统一为Heiti SC，并按图标题、块标题、正文与辅助标签等角色固定字号和字重，PDF使用相同字体。完整规范与生成校验见[配图维护说明](../illustrations/chapter-2/README.md#维护与生成)。

封面单独设置字号；目录列出上册章、节以及下册行业、案例。页眉左侧为报告名，右侧为当前章节，页脚居中显示页码。封面无页眉页脚，前置页使用罗马页码，正文从导论第1页连续编排。原有16张插图、目录跳转、书签、正文引用与来源链接均保留。

复现本预览版：

```bash
python3 scripts/build-pdf.py --output output/pdf/企业数智化转型研究报告-排版预览版.pdf
```

[预览版构建清单](企业数智化转型研究报告-排版预览版.manifest.json)保存字体、字号、正文起页、物理页与显示页码、表题、图题、源文件校验值及内容检查结果。已检查4,300个正文片段、607个图中文字片段和84个图表标题，无缺失或正文空白页；已渲染抽查封面、目录、正文、插图、长表格和下册案例，并扫描全书文字边界。

## 后续更新

先修改原有Markdown正文，再运行[生成脚本](../../scripts/build-pdf.py)：

```bash
python3 scripts/build-pdf.py
python3 scripts/build-pdf.py --chapter 上册-研究报告/02-最小执行单位-从人到任务.md
python3 scripts/validate.py
```

需要Pandoc、Python包`reportlab`及`pypdf`。生成器现已采用上述预览版排版，默认寻找本机WPS的仿宋、macOS的黑体与楷体。插图统一采用简体黑体Heiti SC，正文使用Light、标题使用Medium，与PNG和SVG保持一致；两种系统黑体字库均选择简体字面（TTC索引1）。其他环境可通过`BOOK_BODY_FONT`、`BOOK_HEADING_FONT`、`BOOK_KAI_FONT`、`BOOK_DIAGRAM_FONT`与`BOOK_DIAGRAM_HEADING_FONT`指定覆盖中文的TrueType字体路径。页码自动编排，后续版本页数变化时同步本说明。

脚本读取91份源文档，保留正文、表格及来源信息，省去网页导航与逐篇重复的版本行，将附录D的Mermaid流程图绘制为矢量图。第二章图片优先读取同名SVG，保留矢量清晰度及可检索文字。生成后检查4,300个正文可见文本片段和607个图内文本片段是否完整、是否存在正文空白页及失效的内部跳转；跨页表格按整行换页并重复表头。

[构建清单](build-manifest.json)记录每份源文档的SHA256、章节起始页、PDF校验值及完整性检查结果。重新生成后须渲染PDF，检查封面、目录、章节转折、长表格与流程图。内容检查和排版检查各自保留。
