本文件可用于当前版本的电子分发及后续发行审阅。内容版本沿用源稿；本次汇编未将下册升级为v8.0，也未改变案例事实和效果口径。版本与使用说明及来源边界保留在合订本前言和正文中。

## 后续更新

先修改原有Markdown正文，再运行[生成脚本](../../scripts/build-pdf.py)：

```bash
python3 scripts/build-pdf.py
python3 scripts/validate.py
```

需要Pandoc、Python包`reportlab`及`pypdf`。默认使用macOS上的Arial Unicode与黑体字体；其他环境可通过`BOOK_BODY_FONT`和`BOOK_HEADING_FONT`指定覆盖中文的TrueType字体路径。页码自动编排，后续版本页数变化时同步本说明。

脚本读取91份源文档，保留正文、表格及来源信息，省去网页导航与逐篇重复的版本行，将附录D的Mermaid流程图绘制为矢量图。生成后检查4,178个可见文本片段是否完整、是否存在正文空白页及失效的内部跳转；跨页表格按整行换页并重复表头。

[构建清单](build-manifest.json)记录每份源文档的SHA256、章节起始页、PDF校验值及完整性检查结果。重新生成后须渲染PDF，检查封面、目录、章节转折、长表格与流程图。内容检查和排版检查各自保留。
