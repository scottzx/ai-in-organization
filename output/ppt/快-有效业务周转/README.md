源稿为五章及结语，固定仓库版本为`713f5f442fd199235844b35b02bf806d20914d95`。当前上册已升级为八章及结语的v11.0，MTL、LTC、IPD、ITR分别成章；本PPT与PDF仍为历史演示，保留v8.0框架，页内及讲稿中的章节编号均指源版。

共22页，前20页为主线，后2页为测量与来源附录。适合面向企业负责人作约20分钟分享；讲者备注与配套讲稿保留逐页讲述、依据、案例阶段和原始定位。

## 内容组织

- 1—5页：从上册的执行、任务与流程分析，解释为什么要加快完整业务循环。
- 6—11页：四种快的具体做法，以及经营试验、履约周期、方法复用和资源取舍的案例。
- 12—15页：四流程协同、人与智能体接力，以及智力飞轮怎样让反馈改善下一轮。
- 16—20页：有效业务周转的测量、下游容量、资源配置和实施行动。
- 21—22页：四种快的记录建议及案例来源定位。

## 使用与维护

PPT的文字、图示、箭头、卡片和表格均为原生可编辑对象，可以直接在PowerPoint、WPS或LibreOffice中修改；PDF供核对显示与分享。

演示使用Noto Sans CJK SC。阅读端可安装同名字体以保持版式；PDF已保留原次导出显示。原稿依据为2026年10月13日上册v8.0及对应下册案例，来源版本见[构建清单](build-manifest.json)。讲稿的章节与案例链接固定到该版本，原始公开来源链接保留。

修改源内容时，编辑[content.json](content.json)；修改视觉布局时，编辑[build.py](build.py)。从仓库根目录重建：

```bash
python3 output/ppt/快-有效业务周转/build.py
```

依赖`python-pptx`、LibreOffice、PyMuPDF和Pillow。只生成PPT与讲稿，可使用`--no-pdf`；逐页渲染默认保存到临时目录，可用`--render-dir`指定。构建清单中的来源哈希通过`git show source_revision:路径`读取固定版本，需要本地Git历史包含该提交；当前工作区的章节改名与内容调整不会改变这些来源哈希。

四种快及其指标表达为本次演示基于上册的管理归纳。案例保留原有来源归属与范围：泳装商拍为早期试点；乳企、烘焙、CGL和消防维保为局部使用；达人履约为试点。销量与总毛利额、计划采购金额与年度收益，以及准备时间与运行周期分别表述。
