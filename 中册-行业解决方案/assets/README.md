# 中册行业原图来源

本目录保存中册引用的官方行业场景图谱、总体架构和实施架构摘图。图中模块、文字与连线保持，图名和来源页码在正文注明；完整页面通过发布者的公开PDF链接查阅。

来源记录见[sources.json](sources.json)，包括资料编号、标题、PDF文件页码、公开URL和文件校验值。摘图由仓库脚本从本地已核验副本直接渲染，未改写图中模块和数据。原图中的评级、价值标签和能力范围按原文理解，新增智力服务安排在本书正文中另行说明。

工程机械B02第57页的架构图按PDF内嵌图形边界裁去页边留白；图题、来源及脚注8的参考资料在章内列出。裁切范围、检测方法、整页摘图校验值和输出校验值登记在来源记录中。A11第22—23页图谱已接近满版，保持完整布局。裁切通过源PDF重新渲染完成。
