# 中册行业原图来源

本目录保存中册引用的官方行业场景图谱、总体架构和实施架构摘图，共61张，在31篇行业章中直接嵌入68处。正文可直接阅读图片，点击图片查看原尺寸；相邻图注提供发布者的公开PDF源页，注明PDF文件页码，原文另有印刷页码时同时列出。

来源记录见[sources.json](sources.json)，包括资料编号、标题、PDF文件页码、公开URL和文件校验值。摘图由仓库脚本从本地已核验副本直接渲染，未改写图中模块和数据。原图中的评级、价值标签和能力范围按原文理解，新增智力服务安排在本书正文中另行说明。

图示按PDF可见元素定位，再逐页核查裁切范围。裁切仅去除页面外围留白，保留图内文字、连线、图例、图题、来源及必要脚注，不删改图内布局或水印。图题与来源是独立文字对象时一并纳入，不能把大面积水印误作架构图。图与页脚之间夹有其他正文时，裁片保留完整图题及来源，PDF文件页码与印刷页码在相邻图注中明确登记。

已对首批53张图逐页复核，46张裁去外侧留白，7张接近满版而保留整页；另从既有参考资料补入7张图。行业分篇另补入《中国智慧林业发展指导意见》PDF第23页的总体架构图，图题完整保留，PDF第23页及印刷第21页在相邻图注注明；该2013年图是历史行业与公共体系参照。A11图谱采用完整可见元素边界并留4点边距，保留右下编制说明；美妆日化第47页和智能移动终端第57页同时减少底部留白。工程机械B02第57页保留图题、脚注8与印刷第51页。医疗C11第31页的两幅图及其图题一起保留。

可复现的[裁切与正文嵌入规则](../../scripts/data/middle/图示裁切规则.json)绑定源PDF的SHA256，登记PDF坐标、图题、页码和使用章节。渲染脚本从完整源页生成3200像素长边的图像后按确认边界取图；不会抽取图片对象而遗漏外部文字或水印。输出尺寸、裁切框与文件校验值见来源记录；原PDF不作修改。源图细字较多时可点击图片放大或查看对应PDF源页。
