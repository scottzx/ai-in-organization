# 中册行业原图来源

本目录保存中册引用的官方行业场景图谱、总体架构和实施架构的页面摘图。图名、图中内容和原页码保持原样，具体引用位置见各行业章；完整文件仍通过原发布者的公开PDF链接查阅。

来源记录见[sources.json](sources.json)，包括资料编号、标题、PDF文件页码、公开URL和文件校验值。摘图由仓库脚本从本地已核验副本直接渲染，未改写图中模块和数据。原图中的评级、价值标签和能力范围按原文理解，新增智力服务安排在本书正文中另行说明。

这些引用材料保留原发布者及编制者的署名和权利，不纳入本书原创文字的MIT许可。来源书目见[行业资料库](../../索引/工信部行业数字化转型资料汇总.md)。
