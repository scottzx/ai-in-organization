# 附录A　行业方案选用与能力对照表

以下工作表帮助企业选读行业方案、辨认自身能力和智力服务可增加的作用。填表依据是本企业的实际业务、设备、系统和使用记录，行业文件列出的参考能力与企业已经具备的能力分别记录。后续的现状诊断、目标确认、蓝图、计划、建设与验收，统一采用上册第八章的方法。

## 行业架构与企业实际能力对照

| 对照内容 | 需要记录什么 |
| --- | --- |
| 行业与企业类型 | 本企业主要经营什么对象、处于哪一产业环节、提供什么产品或服务；先选对应独立行业篇，再判断哪些专业模块适用。 |
| 参考文件 | 发布或编制者、完整题名、版本、架构图及PDF物理页或HTML章节。 |
| 方案提供的参考能力 | 模块名称、主要功能、软件设备、数据与模型，以及上下游关系。 |
| 企业现有能力 | 已建系统与设备、实际维护的数据及模型、当前使用范围与接收岗位。 |
| 实际采用依据 | 对应哪批产品、订单、项目或服务，保存在哪里，谁使用，结果如何进入后续工作。 |
| 主要差异 | 尚未具备、尚未使用、专业条件不足或模块衔接受阻的具体位置。 |

已购软件、已联网设备、可运行功能与持续采用分别辨认。可靠表格和人工记录也按实际作用登记，企业规模和系统数量不能代替这项核对。

## 应用模块与智力服务新增价值对照

| 应用模块 | 数字化模块本身承担什么 | 智力服务可增加什么 | 依据、工具与使用者 | 需要核实的价值 |
| --- | --- | --- | --- | --- |
| 按本企业选用模块填写 | 记录、设计、计算、监测、优化、控制或业务处理功能，及其专业条件。 | 协助建造、资料理解、背景协调、原因分析或获准任务处理。 | 使用什么数据、模型和工具，交出什么，由谁判断和采用。 | 是否减少开发或准备工作、缩短等待、扩大处理覆盖，及实际使用条件。 |

行业方案已经列出的工业AI、优化模型、规则程序和自动控制继续保留其专业作用。基础模块同期补建时，分别辨认新形成的数字化能力与服务改变的工作；其他企业披露的收益不能直接填为本企业的预期结果。

## 选用结论与资料回查

| 选用结论 | 应说明的依据 |
| --- | --- |
| 优先了解的模块 | 与本企业的产品、服务和业务差距有什么关系，能形成什么实际能力。 |
| 适合复用的基础 | 哪些企业现有系统、数据、专业模型和人员经验可以继续使用。 |
| 需要补齐的条件 | 哪些对象、版本、采集、连接、工具或专业条件尚不具备。 |
| 候选服务任务 | 服务具体参与哪个模块、哪个动作，新增价值来自哪里。 |
| 需继续回查的资料 | 原图、章节、案例及其来源位置，材料披露的实际使用阶段与限制。 |

确认选用范围后，转入[上册第八章](../上册-研究报告/08-实施建议-从改造机会到可验证行动.md)的实施准备。行业方案用于认识和选择能力，实际工程安排以企业自身条件及相应专业要求为依据。
