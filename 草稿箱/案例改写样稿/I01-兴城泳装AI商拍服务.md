# I01 兴城泳装AI商拍服务

## 1. 企业介绍

本案例的主体是向兴城泳装厂商提供AI商拍产品与服务的团队，泳装厂商是其客户。讨论对象是服务方如何理解客户业务、改进图片制作并形成产品。

## 2. 业务背景与改造目标

泳装厂商需要商品图片用于电商展示，其中大码泳装商拍需求较为集中。图片既要呈现商品，也要赶上销售季节。服务团队尝试借助AI制作客户可用的商品图，减少寻找模特与安排拍摄带来的困难，降低客户拍摄费用。

## 3. 面临的问题

大码泳装的合适模特难找，把衣服寄往海外再拍，还可能错过销售季节。电商展示又要求图片里的衣服与真实商品一致，生成图必须符合具体商品的展示要求。

早期AI图片仍需要大量PS补救，人工修图仍是服务交付中的重要环节。团队还需要理解设计师怎样判断一张图是否合适，仅记录操作步骤，无法解释选图依据。

## 4. 解决方案与实施过程

团队进入客户直播间查看后台，观察运营和设计师每天怎样工作，把图片制作拆成具体步骤。在询问设计师做了什么之外，他们继续追问为什么选择这一张图，梳理实际业务要求和经验判断。

围绕大码泳装商拍的需要，团队尝试人物形状、肤色转换和专用训练。AI参与图像生成与转换，服务团队通过业务观察、理解设计师判断和人工修图来弥补图片可用性的差距。后来上线的产品提供设计、印花和商拍等功能。

## 5. 实施效果

<a id="s-28-f01"></a>

**阶段：试点。**

供方回顾，约80%的图片仍要靠PS补救，交出的图片甚至比真人拍摄更贵；这种情况持续了近一年。

<a id="s-28-f02"></a>

**阶段：局部使用。**

供方称产品于2024年10月上线并服务客户。受访者估计，客户拍摄费用明显下降。

## 6. 分析与启示

**一芥分析：**本案例需要围绕客户可用的商品图评价AI的作用。生成能力、行业判断和人工修图共同影响交付；仅比较生成一张图片的费用，无法说明客户拿到合适图片所需的总投入。后续可以在相同图片要求下，比较拍摄、生成、修图和沟通投入，并核对货图一致性。

受访者还谈到，泳装行业积累的经验移到童装未必适用，投入很大的自研模型也可能很快被通用模型追上。**一芥分析：**服务方需要分别考虑行业经验的适用范围和技术更新对投入价值的影响。
