# R01 瑜伽与普拉提门店AI应用

## 1. 企业介绍

本案例涉及一家瑜伽与普拉提门店。经营者介绍了会员规划文稿、客户沟通分析，以及正在建设的销售陪练工具。资料来自门店经营者访谈，包含自用描述、原型与计划说明。

## 2. 业务背景与改造目标

门店先希望让员工把AI放进当前任务，减少月度会员规划文稿的制作负担，再从客户聊天中寻找沟通调整事项。另一个目标是把老板带教练练习销售的经验整理为陪练工具，减少重复带教投入。

## 3. 面临的问题

### 会员文稿与沟通分析

最初培训结束一周后，员工又不再使用AI。笼统培训没有把工具接到每天需要完成的任务。

经营者还检查客户聊天中的开口话术。材料里聊天回复比例偏低属于诊断时的表现，不是调整后的改善指标。

### 销售陪练建设

销售练习原来由老板带教练进行，重复带教占用老板时间。门店希望把这些经验拆成可以练习的内容。

## 4. 解决方案与实施过程

### 会员文稿与沟通分析

<a id="s-33-f01"></a>

**阶段：局部使用。**

老板直接提供提示词模板，让月度会员规划变得更容易完成。客户答疑仍由人回复，工具辅助的是文稿准备。

经营者又用四千多条聊天记录检查开口话术，得到一些调整待办。这是一项已经发生的沟通分析。

### 销售陪练建设

<a id="s-33-f02"></a>

**阶段：预计（已有原型）。**

门店正在制作销售陪练工具，希望承接原来由老板带领的重复练习。访谈时工具仍在建设，不能写成成熟的对外服务。

## 5. 实施效果

### 会员文稿与沟通分析

受访者称，使用模板后文稿约五分钟可以完成。据受访者介绍，四千多条聊天记录的分析形成了沟通调整事项；它与文稿用时是两个不同任务的结果。

### 销售陪练建设

据受访者介绍，陪练仍在建设。访谈另外描述了已发生的周年庆经营变化：续费客单价有所提高，并称续费率有所提升。客单价与续费率是不同指标，且这些变化不能归为尚未成熟的陪练工具效果。

## 6. 分析与启示

**本书分析：**模板把工具接到明确产物，比笼统培训更容易帮助员工开始使用。客户答疑与专业服务仍由人完成，文稿辅助和沟通分析则承接具体准备任务。

陪练原型要在实际练习中检验。文稿时间、沟通调整与周年庆续费指标分别发生，评价经营贡献时应进一步追踪采用、练习与业务结果的联系。
