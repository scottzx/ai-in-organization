# R02 人物访谈内容团队AI选题探索

[下册索引](../README.md) · [本行业索引](README.md) · [上册研究报告](../../上册-研究报告/README.md)

## 1. 企业介绍

一家自媒体内容团队制作人物采访内容，业务岗位涉及内容制作、生产流转、账号运营和商业化。资料包括实施者自述、团队对话及选题预测原型演示。

## 2. 业务背景与改造目标

真实采访依赖人物、现场和个人思考。团队希望研究AI可以改善哪个业务环节，同时保留真实采访与个人思考。

实施者没有直接把剪辑提速列为优先项，而是先研究选题决定如何影响后续制作投入，再提出选题与爆款的前置判断方向。

## 3. 面临的问题

### 业务调查与改造排序

长素材压缩成十几分钟、反复修改，确实耗用导演时间。但选题一旦选错，采访和制作投入可能全部落空。最耗时的岗位任务与最影响投入结果的业务决定，并不总是同一环节。

### 点赞预测原型

选题判断需要从讨论走到可以尝试的工具。已有稿件和点赞记录可以帮助建立评分维度，但旧内容上的演示与新选题的前瞻判断是不同任务。

## 4. 解决方案与实施过程

### 业务调查与改造排序

<a id="s-19-f01"></a>

**阶段：需求与设想。**

实施者用三天访谈内容制作、生产流转、账号运营和商业化岗位，清洗录音，借助AI形成业务地图，再把问题分成战略、策略、底线和优化几类。

调查后，团队把选题与爆款前置判断排在剪辑提速之前。三天调查与排序已经发生，完整访谈预测系统仍是后续计划；未来还涉及画面、人物和情绪等判断。

### 点赞预测原型

<a id="s-19-f02"></a>

**阶段：预计（已有原型）。**

团队用既有稿件和实际点赞整理评分维度，材料称使用约25个样本，十几分钟做出小工具，并在现场尝试预测。它让讨论中的判断成为可操作的演示原型。

## 5. 实施效果

### 业务调查与改造排序

已经形成业务地图并完成改造优先级排序，选题前置判断成为后续方向。这是调查与决策结果，不能写成内容增长或失败率下降。

### 点赞预测原型

约25个既有样本、十几分钟制作对应原型构建和现场尝试。它证明工具已经做出；对旧稿的演示不能当成样本外预测能力或真实新选题收益。

## 6. 分析与启示

**本书分析：**本案先从业务投入和关键决定倒推切口，避免仅按岗位耗时选择改造对象。调查结果改变优先级，是已经发生的组织动作。

原型可以帮助团队讨论判断方式，预测价值仍要通过独立样本和真实选题检验。应把“做出工具”“预测有效”和“降低投入损失”作为三个不同结果。
