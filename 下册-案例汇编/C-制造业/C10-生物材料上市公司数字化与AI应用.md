# C10 生物材料上市公司数字化与AI应用

## 背景与阅读范围

本篇讨论生物材料上市公司数字化与AI应用。资料性质为第三方实施者访谈自述，各项工作按下文所列阶段分别理解。本文依据公开来源整理与分析，尚未取得独立运行日志或客户验收资料作交叉核验。

<a id="c-18-f01"></a>
## 1. CRM基础与培训陪练分别看

**阶段：局部使用。** CRM与知识库运行后增加陪练和考试；招聘自动一面为独立试点，非全面采用。

这家生物材料上市公司的销售端，仍有纸面台账和个人Excel。团队先判断销售提成属于数据与信息化问题，补CRM、数仓和BI，再引入AI辅助分析。培训也经历一次调整：知识库跑起来后发现，仅能查答案还不足以让新人胜任，于是加上陪练、电子考试和上岗标准，按通过率继续改。正文称新人培训由接近两个月变为约三周，但没有样本和上岗后的质量对照。这一过程说明为什么知识问答需要接到练习与考核；不能把CRM、考试和组织调整的共同结果都记作模型增益，也不能把单个老销售节省的招聘时间乘以整个团队。

**一芥分析：**新人完成培训更快是有边界的线索，仍应检验胜任质量与客户交付。数据基础可先独立解决问题，不能把前置数字化的效果全部归给AI。

**结果口径：**

- 新人培训由接近两个月缩至约三周。 范围：来源描述的销售新人培训。 新人样本、同期对照及上岗后业绩质量未给；不是企业全员培训周期。
- 一位参与招聘的老销售每月原3—4个人天基本释放，可多拜访1—2客户。 范围：单名老销售招聘工作量与机会测算。 不可乘以全部200多人；多拜访是机会，不是已新增客户或成交。

**来源定位：** [NO.18 从纸质台账到AI经营：一家生物科技上市公司的0帧起手数智化](https://assets.datawhale.cn/Datawhale%20FDE%E6%A1%88%E4%BE%8B100.pdf#page=178)｜原书177–184页；PDF178–185页；整理稿L57—65、L67—71、L69—75、L81—81、L83—83、L57—75、L81—85。

## 结果边界与后续观察

- 实施者访谈自述，未取得独立客户、验收文件或运行日志核验；下述阶段依正文限定。
- 二十个编制不等于二十人全部到岗。
- 不能补为医药制造或医疗机构；具体为生物材料。
- CRM、数仓、BI与AI的贡献不能合并为AI独立增益。

## 与组织改造的关系

**一芥分析：**数字化数据基础、练习、考核与AI共同参与培训变化。推广时需要把培训完成和实际胜任分开，并观察上岗后的服务质量，才可能判断更短周期是否形成有效交付。
