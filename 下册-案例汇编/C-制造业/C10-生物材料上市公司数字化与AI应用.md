# C10 生物材料上市公司数字化与AI应用

<a id="c-18-f01"></a>

**阶段：局部使用。**

据 Datawhale《FDE案例100》NO.18（第177-184页）整理。一家生物材料上市公司的销售记录分散在纸面和个人表格里，难以支撑经营分析，新人培训也只靠知识问答。企业先补CRM、数据仓库和报表，再在培训中加入AI陪练与上岗考核，招聘初筛另作试点。实施者称CRM和知识库已在运行、销售新人培训周期缩短。这说明数据基础往往要先于AI应用，而各环节效果需要分别评价。
