# C15 安庆威灵5G零部件制造与追溯

一芥智能研究院｜《企业数智化转型研究报告》下册｜2026年10月18日

## 1. 企业介绍

安庆威灵汽车部件有限公司是美的集团新能源汽车产业项目的建设主体。工信部装备工业5G工厂应用实践汇编记录了其汽车零部件工厂的网络、制造、质量、物流和能源建设。

## 2. 业务背景与改造目标

新能源汽车零部件面对多品种、小批量生产和产品变化，需要快速调整流程，并保证检测、装配与追溯。工厂建设以“终端感知—边缘计算—云端协同”为总体架构，整合MES、WMS和IAC财智云等系统，使设备、物料及生产数据能够共同支撑业务。

## 3. 面临的问题

材料指出，有线网络布线困难、移动设备灵活性低，影响设备协同；新品投产与柔性制造对网络和生产流程提出更高要求。检测结果、加工参数、库存和发货信息还需连续留存，才能在质量问题发生后回查具体产品的生产过程。

## 4. 解决方案与实施过程

<a id="miit-d05-15-f01"></a>

**阶段：已使用。**

端侧对接异构设备数据，边缘侧部署OT数据处理、建模、可视化和本地应用，云侧实行集约管理和多层分发。车间工业网关采集PLC、传感器和RFID数据，通过5G传至总装线看板，供管理者观察进度、效率和异常工位。

在检测环节，搭载AI视觉传感器的协作机器人与中控系统联网：合格零部件转入下一工序，不合格品放入隔离区并触发返工流程。装配环节由视觉识别定位标记，向机械臂发送调整指令。氦气检漏则由检漏仪、自动夹具与充气检测配合完成。

生产追溯把产品标签扫描、设备运行数据、加工参数和质量检测记录上传系统；包装发货时再次扫码，记录进入物流管理系统。仓储区域使用货架传感器、RFID、AGV等设备，管理人员可在终端查看库存、设备和作业进度。

## 5. 实施效果

项目披露，全厂5G覆盖率100%，关键业务响应时延控制在50毫秒内。场景层面，氦气检漏使因泄漏问题造成的后续加工浪费减少70%；库存准确率由85%提高至99%以上。

建设价值部分另列生产效率提高40%、物流成本降低25%、库存周转率提高35%、财务结算效率提高60%。汇编未给出各项指标完整的统计时期、样本及成本构成，本案不将它们归因到某一个模型或某项新增服务。

## 6. 分析与启示

**本书分析：**本案的质量建设把识别结果接到分流、隔离和返工，再把检测记录接到追溯。由此，检验一项智能应用，应同时看识别质量和下一工序能否正确采用，而不只看图像处理速度。

设备采集、网络、MES和物流系统为后续分析提供基础。增加智力服务时，可以据具体产品的异常记录组织原因假设和核查任务，但原因确认、工艺变更及合格放行仍需按企业授权和专业标准实施。
