## 1. 企业介绍

据受访者介绍，本案例主体是一家约20人的电助力单车企业。访谈涉及仪表规格开发、成交订单整理、装配交接、电商运营和品牌内容制作，企业经营者与员工介绍了各自使用AI的做法。

材料由同一主体的多条访谈和岗位叙述组成，另含决策方法教学。教学中的其他企业经历不归入本案例。

## 2. 业务背景与改造目标

团队将AI用于多种日常工作：理解供应商规格，整理订单配置，保存创作要求，汇总员工复盘，以及准备经营决策。各项工作的产物和使用阶段不同，需要分别观察。

这些应用共同涉及一个目标：让信息整理更容易进入后续工作。规格分析要支持与供应商讨论，订单记录要支持装配，内容要求要支持下次制作，复盘汇总要支持行动，经营建议则由人判断和执行。

## 3. 面临的问题

### 仪表规格沟通

供应商提供的仪表规格书篇幅较长。团队需要理解功能，再说明自己的需求，长文档中的表述难以直接支持互动讨论。

### 成交订单与装配

据受访者介绍，原先由两人填表整理订单，复杂配置容易出错。成交信息还需要传给装配同事，记录不清会影响配车。

### 品牌内容审核

老板的修改意见如果只用于当前作品，下次创作仍要重新猜测要求。据受访者介绍，一次reaction视频的审核中，修改意见曾达到约200项。

### 员工复盘与督办

员工复盘需要先收集各自的情况，再整理共识、分歧和待办。信息汇总之外，实际任务还需要经营者督办和协调。

### 场地成本与谈判

房租属于企业经营支出。经营者需要整理场地成本并考虑调整空间，而建议形成以后，仍要与出租方实际谈判。

## 4. 解决方案与实施过程

### 仪表规格沟通

<a id="s-23-f01"></a>

**阶段：预计（已有原型）。**

团队借助AI分析真实规格书、整理讨论点，再制作可交互的仪表模拟器。原来需要在长文档中来回解释的内容，变成能够当场操作和讨论的界面，支持团队与供应商核对需求。产物是需求沟通原型，尚不等同于物理仪表验证。

### 成交订单与装配

<a id="s-23-f02"></a>

**阶段：已使用。**

成交订单进入工作流后，工具将信息整理为结构化记录，写入飞书多维表格，装配同事按记录配车。信息整理与记录由工具支持，配置核对、实际安装和履约继续由人完成。重复填表减少后，运营人员将更多精力用于车型解释、平台规则和销售策略。

### 品牌内容审核

<a id="s-23-f03"></a>

**阶段：已使用。**

品牌员工保存老板每次修改的意见，让工具归纳为后续创作规范。下一次制作可以先参考已明确的要求，人继续判断作品是否符合品牌需要。做法把审核意见从一次修改转为后续制作的依据。

### 员工复盘与督办

<a id="s-23-f04"></a>

**阶段：局部使用。**

团队分别收集员工复盘，借助AI追问并汇总共识、分歧和待办。汇总完成后，老板仍在现实工作中督办、协调和调解。产量、电商等业务另有专门会议，不能把这项复盘做法概括为所有会议已经自动处理。

### 场地成本与谈判

<a id="s-23-f05"></a>

**阶段：局部使用。**

据经营者自述，AI在讨论经营问题时提示场地成本，他据此整理信息、取得建议，再由自己与出租方谈判。AI参与问题发现与建议准备，人作出决定并执行谈判。

## 5. 实施效果

### 仪表规格沟通

据受访者介绍，模拟器使仪表需求更容易当场讨论，帮助团队较早发现理解差异。这一成果属于原型阶段的沟通产物。

### 成交订单与装配

据受访者介绍，订单工作流已经使用，重复整理减少，装配同事有了结构化记录可供接手。据光羽的平行世界节目受访者自述，电商部一人年销售额超过1000万元，该数字是业务销售总额，未经独立核实，不能归为AI创造的净收益。

### 品牌内容审核

受访者举例，一次reaction视频的审核意见由约200项减少到31项。比较限于所述作品及其审核范围，不代表全公司错误率的变化。

### 员工复盘与督办

经营者将其中一段复盘信息处理概括为从一下午缩到约20分钟。这一自述对应收集、追问与汇总信息的环节，后续执行和任务关闭仍由人管理。

### 场地成本与谈判

长访谈中，经营者称节约了租金和决策教学方面的支出；据光羽的平行世界节目受访者自述，相关节省约400万元。其余分项金额只见口述，本书不采用；未来累计属于估算，不计入当期已实现节省。

## 6. 分析与启示

**本书分析：**本案的应用没有共享一个效果指标，而是分别改变了不同工作产物：可交互的需求原型、结构化订单、创作规范、复盘待办和谈判准备。组织协作围绕这些产物接续，人保留安装、品牌判断、任务推进和经营决策。

评价时应逐项检验产物能否支持下一环节，并计入人的核对与执行投入。单次审核变化、复盘节时和经营者节租自述分别有自己的比较范围，不能相加推算公司整体AI收益。
