# C22 盐城维信电子5G柔性电路板协同制造

## 1. 企业介绍

盐城维信电子有限公司从事柔性印刷电路板（FPC）制造。工信部电子信息5G应用实践汇编收录其智能制造工厂，记录了研发、排产、设备、质量、物流、供应链和追溯等建设。

## 2. 业务背景与改造目标

柔性电路板产品迭代快，多品种小批量生产需要频繁换线。项目希望通过设备联网、边缘计算及平台集成，使研发资料、客户订单、产能、生产参数和质量信息共同支撑制造，改善新产品导入与变更响应。

## 3. 面临的问题

材料指出，传统设备联网率低，关键工艺数据采集不及时，生产调度滞后；产线柔性和换线效率不足；质量检查依赖人工目检；AGV与机器人等移动设备需要可靠通信。盐城生产基地与苏州研发中心还存在跨域设计数据协同需要。

## 4. 解决方案与实施过程

<a id="miit-d07-01-f01"></a>

**阶段：已使用。**

项目建设5G专网与边缘服务器，将994台生产设备通过网关、CPE或模组接入，并连接ERP、MES、PLM、WMS等系统。AI质检与AGV调度的计算部署在边缘，减少远程传输对实时业务的影响。

研发使用PLM组织资料，设计与实验设备上传数据，协同平台支持数字设计、仿真及验证，并将产品设计转换为生产制程文件。排产则将APS与ERP、MES、MRP相连：根据产品对应设备的产能、订单、出货期和优先级分配资源；ERP识别订单变化后，APS反馈调整方案，工艺研发信息通过集成更新到MES。

质量应用对检测设备加装5G网关，图像进入企业MEC边缘云，由专家系统管理检测任务，深度学习算法识别尺寸偏差、表面缺陷与色差等。工艺合规环节采集原材料检测、关键参数与成品检验记录，形成可追溯数据。

企业还建设工业互联网标识解析节点，为原材料、生产过程和物流信息建立唯一标识，并对接SRM开展供应链数据协同。工序PDA扫码记录物料、设备与人员，支持从原料到成品的追踪及问题逆向回查。

## 5. 实施效果

项目披露，研发周期平均缩短20%，设计到生产的转化效率提高约30%；APS在订单变化后可于15分钟内反馈调整方案，换型换线时间平均缩短35%，在制品库存减少25%。这些指标分别对应研发与排产场景。

质量追溯场景披露，单件全流程追溯数据录入由人工记录3分钟缩短为扫码10秒，问题分析定位由平均4小时缩短至15分钟以内。机器视觉检测另列缺陷识别准确率99.8%以上、漏检率低于0.2%。汇编未提供测试样本分布、完整统计期及独立审计，数字按项目披露口径记录。

## 6. 分析与启示

**本书分析：**研发变更需要转换为制程文件，订单变化需要进入排产，质量问题需要反向找到工序及物料。三项应用都有明确的业务对象和采用去向，能够为进一步建设提供接口与记录基础。

增加智力服务时，可以沿现有PLM、APS、MES和标识解析体系，选择变更核对、异常解释或系统开发等任务，再检验结果能否进入生产。原有仿真、优化和视觉模型已经承担部分智能任务，新增通用智力服务的贡献应根据具体工作另行核算。
