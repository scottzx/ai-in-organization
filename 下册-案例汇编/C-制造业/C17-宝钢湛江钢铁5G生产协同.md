# C17 宝钢湛江钢铁5G生产协同

一芥智能研究院｜《企业数智化转型研究报告》下册｜2026年10月18日

## 1. 企业介绍

宝钢湛江钢铁有限公司是钢铁生产企业。工信部原材料工业5G应用实践汇编收录了其基于独立专网的智慧绿色钢铁工厂，涉及炼铁、炼钢等核心生产环节，以及行车、物流、设备维护和作业监控。

## 2. 业务背景与改造目标

钢铁现场存在高温、粉尘和危险作业，设备分散且移动终端较多。项目通过企业独立5G核心网连接信息主干网、工业控制网和视频监控网，使设备控制、视频与生产数据能够支撑远程作业和资源协同。

## 3. 面临的问题

材料指出，大量设备需要人工点检，工作依赖现场人员及其经验，效率与作业环境存在约束。移动、离散设备需要稳定传输数据；两个独立板坯库的行车跨库作业，还需要同步地面安全系统和设备联锁。

## 4. 解决方案与实施过程

<a id="miit-d04-08-f01"></a>

**阶段：已使用。**

项目采用端、边、云三级架构，端侧接入AGV、摄像头及传感器，边侧使用独立专网进行传输和预处理，内网服务器承担应用决策。企业部署两套跨机房容灾的独立5G核心网，建立统一数据标准和数据关联。

热轧板坯库为行车加装5G CPE，将控制指令和高清视频分别送入工控网与视频网。两个库区地面管理系统据此相连，行车跨库交替作业时，地面设备联锁和安全区避让信息可以交互，支持行车统一调度。

炼钢设备维护通过LoRa采集高压开关、行车、电机等设备的振动、温度和电流，经5G传往边缘节点，由AI算法评估健康状态、预警故障和预测剩余寿命。

全厂车辆配备5G终端，运管机系统按“分区配车、班中调整”派单；驾驶员接收并确认作业指令，车辆接单、装货、运输、卸货的状态持续回传。

## 5. 实施效果

项目披露，跨库行车协同使综合作业效率提高约25%；炼钢智慧设备监测使设备故障率降低30%、运维响应时间缩短50%，年维护成本节约超过200万元；全域物流监测使车辆平均等货时间缩短约25%、运输效率提高约15%。各结果对应的业务范围不同，汇编未提供独立审计和完整对照数据。

项目概述与部署部分对场景数量使用了不同统计表述，本案以具体应用过程为依据，不将数量差异解释成已验证的新增范围。

## 6. 分析与启示

**本书分析：**跨库行车共享首先依赖安全联锁、位置和控制信息能够可靠交换，物流优化还依赖驾驶员确认和实际装卸状态。网络能力只有进入可执行的协作关系，才能产生资源共享价值。

原方案已经包含自动化和AI。后续增加智力服务，可针对维护告警、调度异常或系统集成承担新的具体任务，但需以现有控制与业务系统为依据，分别核验建议被采用后的结果及全部投入。
