# C19 中建材宜兴新能源5G超薄玻璃生产

一芥智能研究院｜《企业数智化转型研究报告》下册｜2026年10月18日

## 1. 企业介绍

中建材（宜兴）新能源有限公司成立于2016年，隶属凯盛新能源，开展超薄高透光伏玻璃研发制造。工信部原材料工业5G应用实践汇编记录了其光伏玻璃基板生产线的数字建模、设备协同、质量、物流和能源建设。

## 2. 业务背景与改造目标

超薄光伏玻璃生产需要稳定控制熔化、压延、退火、镀膜等工艺，并连续协调薄片搬运、检测和存储。项目以5G工业互联网与数字孪生为基础，建设端、边、云架构及统一管理平台，把现场参数与生产、质量、能耗数据连接起来。

## 3. 面临的问题

材料指出，工艺设计、生产效率、质量管控、物流和节能均有改进需求，复杂环境下设备部署及运维也存在困难。窑炉温度、生产参数与质量结果需要相互对应，才能观察异常并及时调整。

## 4. 解决方案与实施过程

<a id="miit-d04-13-f01"></a>

**阶段：已使用。**

端侧通过OPC UA接入90余类工业设备，PLC、视觉系统等经5G和MQTT传输数据；边侧设置专用UPF及实时计算；云侧数据中台整合ERP、MES，用200多个数据资产标签治理数据，并生成小时级能效分析报告。

数字模型覆盖原片、深加工、环保装置和熔窑。现场温度、压力等参数映射到三维模型，用于观察温度曲线、热分布，模拟压延参数对质量的影响，并比较退火窑实际与仿真数据。

熔窑南北火区域的传感器采集温度，控制系统根据数据计算调节策略，降低偏高侧燃烧强度或调整另一侧温度。原片检测、光谱测量和镀膜出口检测分别采集气泡、结石、透光率、膜厚与均匀度等质量信息。

搬运设备结合视觉和算法识别玻璃尺寸、厚度与位置，协调翻板、铺纸、上下片及AGV；堆垛依据品质等级和批次存储。追溯记录同时关联人员操作、设备参数、原材料批次、工艺和环境。

## 5. 实施效果

项目披露，产能利用率提高26%，计划外停机时间减少30%，能耗成本降低12%，成品质量合格率达98%以上；仓储成本降低23%，物流时间缩短32%。这些结果来自项目汇编，未提供独立审计或完整统计基线。

同页将设备维修成本降低13%与事故发生率降低30%写为“预计”，本案保留其预计性质，不计入已经实现的效果。该页还分别使用“次品率”和“不合格品率”两个指标，本案不将它们合并或重复计量。

## 6. 分析与启示

**一芥分析：**本案数字化已包括三维建模、仿真和工艺计算，网络化连接工艺设备、机器人及企业系统，智能化进入识别、策略计算与动作执行。行业方案需要沿这些原模块继续完善，才能保持对实体生产的解释力。

后续引入智力服务，可帮助核对工艺资料、解释异常证据或开发集成能力；窑炉控制与品质放行仍需按原有工程约束验证。验收还应区分模型反映是否准确、控制是否稳定、产品是否合格和总体成本是否改善。
