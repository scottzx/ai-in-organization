# C24 海外工业企业物料诊断

<a id="c-08-f01"></a>

**阶段：阶段未明。**

据 Datawhale《FDE案例100》NO.8（第76-85页）整理。一家匿名海外工业企业的多个团队共用一套老ERP，员工常常找不到已有物料，于是重复建档。实施者没有先改搜索，而是追问其后果，把问题定位到同物异名带来的错买、重买、积压和报废。目前只完成诊断和优先级讨论，数据清洗与语义检索仍是计划。它示范了从一线困难出发、沿业务后果确定改造优先级的诊断方法。
