# C14 铁拓机械5G研发生产与设备协同

## 1. 企业介绍

福建省铁拓机械股份有限公司位于福建泉州，是沥青混合料搅拌设备制造企业。工信部发布的《2025年5G工厂典型应用实践（装备工业）》收录了其5G智能制造产业园项目。材料称，企业于2019年建成智能制造园区，随后以5G虚拟专网、工业互联网平台及应用场景推动产供销数字化。

## 2. 业务背景与改造目标

工程机械生产需要把设计图纸、工艺参数、物料和设备状态接到实际工序。项目希望打通ERP、PLM、焊接云平台等系统，使研发变更、生产执行、设备维护和仓储供料能够接续，同时减少高危焊接作业的现场人员配置。

## 3. 面临的问题

材料将设备数字化水平低、网络性能不足和生产协同粗放列为主要问题。图纸存在分级权限、移动调阅和及时下发的需要；设备联网与参数采集不足，也限制了远程控制、故障诊断和维护安排。仓储盘点依赖人工，影响库存更新和生产供料。

## 4. 解决方案与实施过程

<a id="miit-d05-09-f01"></a>

**阶段：已使用。**

项目建设“端—边—云”架构，以5G虚拟专网融合工业以太网；终端通过工业网关联网，边缘节点处理数据、下发控制指令，云端整合生产调度、设备管理和数据分析。原有ERP、PLM继续参与业务，并通过接口连接。

材料所列应用包括：设计环节由PLM管理图纸并与ERP生产计划同步变更；焊接环节建设远程工作站与视觉焊接应用；维护环节对重点设备加装传感器、以历史数据建立设备健康模型；仓储环节以5G PDA扫码关联ERP出入库单据。具体工艺参数、设备配置和算法细节以原文为准，本篇不作转述。

## 5. 实施效果

原文在项目概述中写道：“机器人动态调整参数，焊接合格率提升至99.2%；③预测维护，AI模型预测设备故障，非计划停机减少60%；④智能理货，5G PDA实现仓储动态调度，盘点周期缩短60%。”[1] 以上为项目方在官方遴选汇编中的披露，各项对应不同场景，不能相加为总体收益，也不能视为独立验收结论。

## 6. 分析与启示

**本书分析：**本案可借鉴的基础，是把图纸版本、工序、设备参数和ERP记录接到真实生产动作。数字化已包含三维表达与参数计算，网络化连接设计人员、车间设备和业务系统，智能化则在视觉识别、路径调整和健康预测等具体任务中体现。

已有自动化、规则诊断和AI模型的贡献需要分开考察。企业若在这一架构上增加智力服务，可先核对图纸变更能否被正确理解并落实、报警是否形成有效处理，再评估新增分析或开发服务的价值。本案原有收益不构成新增智力服务的收益证明。
