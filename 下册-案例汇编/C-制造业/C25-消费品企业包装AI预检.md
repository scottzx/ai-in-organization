# C25 消费品企业包装AI预检

<a id="c-19-f01"></a>

**阶段：局部使用。**

据 Datawhale《FDE案例100》NO.19（第185-195页）整理。一家匿名消费品企业的包装设计稿在投产前要经过文字、法规和渠道规范等多类检查，SKU增多后审核排队积压。团队把审核逐项拆开，确定性计算交给程序，AI给出带来源和置信度的提示，并把预检前移到设计提交环节。实施方称部分基础问题能更早发现，最终判断仍归专业人员。这说明审核类场景应把程序计算、AI提示和专业判断分开安排。
