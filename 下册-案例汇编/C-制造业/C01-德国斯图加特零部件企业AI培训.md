# C01 德国斯图加特零部件企业AI培训

<a id="c-01-f01"></a>

**阶段：已使用。**

据 Datawhale《FDE案例100》NO.1（第6-13页）整理。一家德国中小零部件制造商面临老师傅经验难以留存、新人上手慢的问题，熟练员工掌握的材料、参数和异常处理多是说不清的隐性知识。实施团队跟岗观察后整理知识，再把问答能力接进新人培训，复杂情况仍由师傅带教。来源未提供可比较的改造前后培训时长。它说明经验传承要把采集、学习入口和师傅带教接成一条线，成效应看新人上岗后的实际操作。
