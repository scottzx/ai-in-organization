# C16 大连中远海运重工5G船舶修造协同

## 1. 企业介绍

大连中远海运重工有限公司隶属中远海运重工有限公司，开展船舶修理、特种船建造及海工装备制造。其5G全连接工厂项目覆盖设备、分段物流、焊接工艺、能源和仓储等环节，已被收入工信部装备工业应用实践汇编。

## 2. 业务背景与改造目标

船舶造修需要在分散厂区和密闭舱室组织多人、多设备作业。项目以“1张5G双专网、1个工业互联网平台、N个5G应用”为总体架构，改造设备接入并整合现有业务系统，希望改善通信、设备协同和精细化管理。

## 3. 面临的问题

厂区范围广、布局分散，舱室封闭使有线部署困难，Wi-Fi还存在盲区与波动。起重机、焊机等设备长期缺少数据互联，限制状态维护与协同作业；物流调度、工艺合规和能耗管理较依赖人工经验。

## 4. 解决方案与实施过程

<a id="miit-d05-19-f01"></a>

**阶段：已使用。**

项目联合两家运营商建设双专网，将MEC部署到厂区，改造起重机、焊机、机器人和能源终端的通信能力。工业互联网平台通过标准接口接入现场数据，整合ERP、CIMS、MES和能源在线监控平台。

对舱室现场，热风机系统结合5G、HPLC电力载波和Mesh自组网采集环境数据并远程调控；现场监测另用5G与LoRa混合组网，使舱内数据经甲板回传，支持报警和风机联动。

分段物流对运输车辆加装5G模组，融合RTK和北斗定位，调度系统根据船舶分段工艺和堆场占用生成配送路径与指令。起重机防碰撞应用结合现场图像和CAD图纸建立三维模型，以包围盒算法计算设备位置与运动，形成碰撞预警。

智慧焊接平台下发标准工艺参数WPS，采集实际焊接参数并与工艺库比对，检查是否处于授权与标准范围。仓储系统以SAP WM为基础，通过条码、RFID和5G采集出入库信息，建立标准库位模型。

## 5. 实施效果

项目披露，热风机远程调控使能耗成本降低30%、人力成本降低20%；分段物流效率提高33%，配送准时率99.7%，运输等待时间减少60%。焊接工艺校验部分披露，不良品率由3%—5%降至1%—1.5%。

这些结果分别针对供暖、分段运输和焊接应用。汇编另以“千万元计”描述年节约生产运营成本，但未给出完整核算表。本案保留各场景范围，不把设备故障诊断与预测维护两处重复列出的同组指标再次累计。

## 6. 分析与启示

**本书分析：**本案说明，行业网络化既包括系统接口，也包括密闭空间通信、移动装备和跨区域生产协同。三维防碰撞、工艺参数核对和物流优化承担不同任务，不能以统一的“AI应用”概括其技术机制。

在原架构上增加智力服务，应沿分段、焊缝、设备和物料等对象读取既有记录，先解决交接和异常说明，再选择可验证的分析、开发或协调任务。设备控制与安全联锁的边界，需要按现场工程要求确认。
