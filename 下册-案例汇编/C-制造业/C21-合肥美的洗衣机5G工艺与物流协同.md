# C21 合肥美的洗衣机5G工艺与物流协同

一芥智能研究院｜《企业数智化转型研究报告》下册｜2026年10月18日

## 1. 企业介绍

合肥美的洗衣机有限公司从事洗衣机研发、制造和销售。汇编记载，其基地拥有11条洗衣机生产线，并配套电子、钣金、注塑、模具等自制件车间，经营美的、小天鹅、COLMO及东芝等品牌。

## 2. 业务背景与改造目标

项目以5G专网、MEC边缘计算和工业互联网平台连接研发、品质、物流、生产、EHS及能源等业务。建设目标包括定制生产、全流程可视化和供应链协同，使销售、制造、物流及供应商能够围绕需求组织工作。

## 3. 面临的问题

多生产线与自制件车间需要协同，工艺参数、节拍、缺陷、能耗及物流状态分属不同设备和系统。汇编的建设需求强调对异常设备和参数快速定位，推进人、车、物数据衔接，以及对生产与物流数据的实时透明管理。材料未提供每项应用的详细改造前基线。

## 4. 解决方案与实施过程

<a id="miit-d06-07-f01"></a>

**阶段：已使用。**

项目将UPF、MEC和专用基站部署到园区，端侧接入534个5G终端，边缘计算就近处理数据，并与企业私有云协同。

在注塑工艺中，PLC取得设备注射信号，经5G送至SCADA展示。工艺参数推优进一步关联MES上下机、自检缺陷、节拍、能耗及设备利用率数据，经算法计算效率与良率方案，过程按“SCADA取数—工业云存储—MES确认—SCADA反写”衔接，结果用于指导生产。

物流方面，MES下达配送指令，由AGV送到岗位。PDA扫描物料标签并绑定工装车，实现无纸化入库；条码和UWB定位等信息通过5G进入WMS，支撑自动入库。

能源系统采集水表、电表数据并集成ESG系统，依次进行分析、策略计算及调度下发。智慧配电房另外使用AI巡检机器人采集数据并进行分析、预警和故障诊断。

## 5. 实施效果

汇编在建设价值部分披露，先进用例敏捷部署效率提高48%、老旧变更部署成本降低35%；端到端品质检验效率提高52%；订单交付效率提高56%、过程品质不良下降36%。

这些是项目总体和若干应用的汇总口径，未逐项披露统计时期、分母及总投入。其中“老旧变更部署成本降低35%”由原文列在5G与先进数字技术部署项下；原文未单列生成式AI辅助开发的投入与贡献，不能将35%作为新增智力服务开发降本的测量。

## 6. 分析与启示

**本书分析：**注塑参数推优提供了具体的采用链条：取数、存储、计算之后还有MES确认和SCADA反写。行业方案既需要说明计算能力，也需要交代参数如何进入生产。

企业已有跨系统与设备的基础，新增智力服务可以从解释候选参数、核对异常依据或辅助构建工具等任务切入，再检验工程人员的确认投入、实际采用和质量变化。既有系统改善与新增服务贡献分别核算，才能判断进一步建设是否值得。
