# C18 广州石化5G设备与作业管控

一芥智能研究院｜《企业数智化转型研究报告》下册｜2026年10月18日

## 1. 企业介绍

本案主体为中国石油化工股份有限公司广州分公司，简称广州石化。其5G工厂项目已收入工信部原材料工业应用实践汇编，涉及泵群维护、移动作业票、环境监测、巡检和应急协同。

## 2. 业务背景与改造目标

石化装置连续运行，现场具有高温、高压、易燃易爆及腐蚀等条件。项目以5G、下沉用户面网元UPF和边缘计算建设专网，在现场数据采集与企业平台之间提供连接，支持安全、环保和设备运行管理。

## 3. 面临的问题

材料指出，零散设备缺少统一接入，炼化业务应用的数据割裂，监测终端统筹管理效率不足；事故时应急指挥也存在互联互通困难。泵群故障与作业违规都需要及时发现，并让维护或现场监护人员采取行动。

## 4. 解决方案与实施过程

<a id="miit-d04-01-f01"></a>

**阶段：已使用。**

网络建设区分防爆与非防爆区域：前者使用符合防爆认证的微站和CPE，后者部署通用宏站和室内分基站。专用UPF实现数据本地卸载，边缘节点提供应用集成、视频和算法能力，现场终端连接企业或集团—企业两级工业互联网平台。

泵群监测采集振动、速度等测点，界面展示实时值、指标和波形。系统结合振动谱图、故障库及AI模型生成诊断和健康预测，异常信息推送设备人员；人员到现场核查，再填报调整参数或安排检修等处理措施。

移动作业通过安全卫士APP记录开票、JSA分析、气体录入、安全措施、交底和签发等过程，并结合定位落实部门、人员、时间、地点要求。作业票填写相应摄像头，监护人员点击开始作业后，票据信息推到AI推理平台，系统按作业类型调用识别算法，并把不安全行为告警发给现场监护人员查看。

VOCs监测把排放因子、气象和走航位置等数据关联到地图。环保人员发现超标后，可通知泄漏检测与修复团队到场定位和修复；电子鼻另结合机器学习进行成分识别、短信告警与定位追踪。

## 5. 实施效果

汇编在泵群预测维护场景中披露，设备平均无故障运行时间延长15%、维护费用降低20%。作业监护和VOCs场景主要说明了信息传递与现场响应过程，未单独给出可核算的效果比较。

建设价值部分称5G应用场景总新增利润为1087.7万元，未披露统计周期和完整核算构成。本案按项目原文记录该汇总口径，不据此推算单项AI服务的利润贡献。

## 6. 分析与启示

**一芥分析：**本案提供了明确的人机交接：模型发出泵群告警后，设备人员现场核查并填报措施；视频识别把结果交给现场监护人员。诊断输出和业务处置在流程中各有承接者。

后续增加智力服务，可围绕原有设备、票据和环保记录帮助组织依据、核对缺失或归纳处理经验。是否扩大执行授权，应以现场安全要求和实测可靠性判断，原项目披露的利润和维护效果继续归属于原建设。
