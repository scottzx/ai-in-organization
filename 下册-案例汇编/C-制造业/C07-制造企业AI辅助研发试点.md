# C07 制造企业AI辅助研发试点

<a id="c-07-f02"></a>

**阶段：试点。**

据 Datawhale《FDE案例100》NO.7（第67-75页）整理。一家匿名制造企业用几天时间试用AI辅助研发，分别观察编码、文档和测试三类任务。小组反馈编码和文档有所提速，测试变化不大。这只是短期、分任务的自述，不能合成为整体研发节省。它提醒企业在评价研发提效时保留任务差异，并用更长周期检验缺陷和交付质量。
