# C13 移动餐车出海企业AI销售准备

一芥智能研究院｜《企业数智化转型研究报告》下册｜初稿 v8.0｜2026年10月13日

## 1. 企业介绍

本案例主体是一家移动餐车出海企业，经营者为一位受访企业主。受访者介绍，企业由贸易转向工厂业务，直接生产餐车并面向海外客户销售。

案例资料是经营者的自用描述和业务规则说明，围绕询盘、销售准备和主动跟进展开。

## 2. 业务背景与改造目标

企业从已成交客户的经历中看到多次主动联系的重要性，希望把业务员各自的跟进习惯整理成共同动作。

AI被用于整理产品、背书和成交经验，为业务员准备客户联系所需的材料；询盘回复、后续跟进和线索回收则按企业规则组织。

## 3. 面临的问题

个人习惯难以形成统一跟进节奏。询盘进入以后，何时回复、何时再次联系、长期没有回应的线索如何处理，都影响销售人员能否持续推进。

业务员还需要理解产品和企业能力，准备可靠的客户沟通内容。资料整理与具体服务相互关联，准备完成并不代表客户已经接受报价或形成订单。

## 4. 解决方案与实施过程

<a id="s-36-f01"></a>

**阶段：局部使用。**

企业要求询盘在一小时内回复，之后按几个时间点继续跟进，多次无回应的线索再回公海。这套安排来自企业对成交客户跟进经历的整理。

AI辅助组织产品、背书和成交经验，支持业务员进行准备。受访者明确强调销售仍需要人的服务：实际联系、报价和承诺由人主导，材料整理和共同规则帮助人员按节奏开展工作。

## 5. 实施效果

企业已经整理自身经验和跟进要求，AI参与销售准备，跟进动作有了共同的时限与记录思路。现阶段资料覆盖经验整理、销售准备和跟进要求，按局部使用呈现。

据抖音视频（ID 7639644564847889718，2026-05-14）受访者自述，企业年营收约1.2亿元，属于企业历史营收，未经独立核实，不能归为AI贡献；访谈中用于解释的转化率是设例，不作为本企业改造后的实测效果。

## 6. 分析与启示

**本书分析：**本案可借鉴的是，把准备材料、回复时限、后续跟进和线索回收连接成共同工作要求。AI参与内容准备，人员继续承担客户服务和承诺，组织通过记录检查动作是否执行。

其他外贸企业应按自己的产品与客户条件验证跟进节奏，并观察有效回复、线索推进和人员投入。共同规则能够支持销售管理，其经营效果仍需真实业务数据检验。
