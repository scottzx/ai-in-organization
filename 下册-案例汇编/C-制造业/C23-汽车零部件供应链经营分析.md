# C23 汽车零部件供应链经营分析

<a id="c-20-f01"></a>

**阶段：局部使用。**

据 Datawhale《FDE案例100》NO.20（第196-205页）整理。一家匿名汽车零部件供应链企业销售维修零部件，并在厂内组装加工；企业此前已上线ERP。老板要知道订单走到哪一步，仍需向不同人员询问；要核对应付款，也难以直接看清它由哪些业务记录形成。实施团队保留ERP，围绕订单链条重新关联已有数据，并通过飞书推送基础异常提醒。项目刚上线，异常处置和成本改善尚无数据。这个例子说明，信息化之后企业仍可能缺少把记录连起来回答经营问题的能力。
