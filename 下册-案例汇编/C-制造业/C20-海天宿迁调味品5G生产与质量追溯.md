# C20 海天宿迁调味品5G生产与质量追溯

一芥智能研究院｜《企业数智化转型研究报告》下册｜2026年10月18日

## 1. 企业介绍

本案主体为佛山市海天（宿迁）调味食品有限公司，属于调味品制造企业。工信部消费品工业5G应用实践汇编以“海天调味品5G全连接工厂”收录其生产、包装、质量、物流及能源建设。

## 2. 业务背景与改造目标

调味品生产需要保持发酵与灌装稳定，按不同规格快速换产，并能够从问题产品回查原料及过程。项目建设“端—边—云”架构，连接设备和业务系统，形成生产模拟、柔性制造、物流、追溯等13个应用场景。

## 3. 面临的问题

材料指出，原有数据孤岛和设备协同不足，网络难以满足高速灌装、实时质检等应用对通信的要求。多规格混线生产需要将订单、设备状态和生产指令及时联系；质量问题需要关联原料批次、生产及检测信息。

## 4. 解决方案与实施过程

<a id="miit-d06-23-f01"></a>

**阶段：已使用。**

关键设备经5G网关、CPE接入，厂区部署56个PRRU，边缘控制器和网关处理实时业务，企业工业互联网平台集成各系统。包装线将MES与供应链平台连接，APS依据设备状态和订单动态排产，调整工艺路线及资源。

灌装应用对19台套设备联网，AI算法根据实时数据动态纠偏灌装参数。包装视觉检测使用40台高清摄像头检查喷码、标签和封膜等外观，识别结果反馈给剔除装置，不合格品由伺服电缸剔除，检测记录进入MES质量档案。

生产追溯连接喷码机、检测机等102台套设备，采集“一物一码”和原料批次，集成MES、SCADA和WMS数据。设备点检人员使用手持终端查看状态、接收报警并回传任务结果；预测性维护另使用振动、电流数据和AI模型形成维护计划，推送移动端执行。

## 5. 实施效果

汇编披露，柔性制造使换产时间缩短30%，多品种小批量订单交付周期缩短20%；灌装精度控制在±2.5克内；包装视觉检测准确率达99.6%，年减少质量损失超过150万元。追溯场景的问题定位时间缩短20%，追溯准确率超过99.9%。

各指标分别对应排产、灌装、外观检测和追溯。汇编未给出检测准确率的样本类别、漏检与误剔除明细，年减少损失也未提供完整核算过程，结果按项目披露口径使用。

## 6. 分析与启示

**一芥分析：**食品方案可以从既有工艺控制、排产、剔除和追溯继续展开。视觉识别的结果已经进入设备动作与质量档案，追溯则把产品与原料、过程联系起来，为问题处置提供依据。

增加智力服务时，应选择记录核对、异常归纳、投诉资料组织或维护协调等明确任务，并核验是否缩短实际处理周期、减少遗漏或降低完整成本。原材料中已有AI，新增服务的效果需另行比较。
