# C02 非标制造企业AI报价

## 1. 企业介绍

本案例涉及一家非标制造企业。其售前报价需要根据客户图纸理解材料、尺寸、结构和工艺，再结合企业物料、供应商及成本规则形成报价。

资料来自第三方实施者访谈，使用方是制造企业，实施团队参与方案调整和上线磨合。

## 2. 业务背景与改造目标

报价串联读图、物料、工艺、成本和对外报价，多个岗位需要交接信息。实施团队希望减少反复处理的工作量，并使释放出的时间用于客户和业务工作。

项目最初试图让模型理解图纸后直接出价，实际试用促使团队重新划分模型、企业规则与人的职责。

## 3. 面临的问题

图纸理解只是报价链条的一部分。模型直接给出的价格经常与企业真实成本对不上，难以承接对外报价的要求。

报价需要企业特定的物料、供应商价格和计算规则，多个人之间还要传递、核对相关信息。把全部环节合成一次模型回答，会掩盖不同依据之间的差异。

## 4. 解决方案与实施过程

<a id="c-17-f01"></a>

**阶段：已使用。**

实施团队将直接出价的方案拆成分段协作：模型先抽取图纸中的材料、尺寸和结构，后续计算回到企业自己的物料、供应商与规则库，每单经人工校准后才对外输出。

团队用真实订单试用，再逐步推广到报价工作。模型负责图纸信息提取，企业规则提供计算依据，人负责校准和对外输出。受访者还说明，企业最终调整了相关人员的工作安排与KPI，使释放出的时间能够转向客户和业务。

## 5. 实施效果

受访者称，售前报价相关工作量至少减少50%。这一自述对应报价中的相关工作量，不能换写成报价成本或耗时下降50%，也不能据此推算订单增长。

企业对工作安排和KPI的调整已有来源陈述。把时间用于更多客户、项目和订单是经营方向，不能据此计算已实现的新增收入。

## 6. 分析与启示

**一芥分析：**本案的关键调整是依据企业成本条件重新划分工作。模型抽取图纸信息，企业规则计算，人校准并承担对外输出责任，三者围绕同一报价产物衔接。

工作量减少后，组织还需要安排这些时间做什么。KPI调整提供了实际动作，但应继续检验报价准确性、人工复核投入和新增业务表现，才能判断完整收益。
