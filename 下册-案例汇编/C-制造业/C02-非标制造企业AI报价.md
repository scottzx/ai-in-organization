# C02 非标制造企业AI报价

<a id="c-17-f01"></a>

**阶段：已使用。**

据 Datawhale《FDE案例100》NO.17（第165-176页）整理。一家非标制造企业想用AI加快售前报价，却发现模型直接给出的价格与真实成本对不上。后来报价被拆开处理：模型读图提取要素，企业自己的规则库算价，人工逐单校准后对外答复。受访者称报价工作量明显下降，但准确率和新增业务没有独立数据。这个例子支持本书的看法：AI进入核心业务时，应按责任划分模型、企业规则和人的分工。
