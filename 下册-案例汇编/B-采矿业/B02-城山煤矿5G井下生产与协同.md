# B02 城山煤矿5G井下生产与协同

## 1. 企业介绍

城山煤矿是鸡西矿业（集团）有限责任公司的煤矿。本案依据工信部能源交通5G应用实践汇编，记录该矿井下网络、综合管控、三机协同和监测维护建设。

## 2. 业务背景与改造目标

项目由矿业集团与通信及矿山技术企业共同实施，形成“一张网、一朵云、一平台、N个子系统”架构。目标是把采掘、运输和安全管控的信息接到综合平台，支持少人化、可视化生产。

## 3. 面临的问题

原有开采方式较依赖人工操作，不同生产环节协同不足。井下环境复杂，传统监测难以及时、全面掌握设备、人员及环境变化，异常信息需要传到能够组织处置的人员。

## 4. 解决方案与实施过程

<a id="miit-d08-02-f01"></a>

**阶段：已使用。**

矿用5G与万兆工业环网、超融合服务器共同建设数据中心及智能综合管控平台。MEC在煤矿边缘处理本地业务，井下巷道和工作面的射频单元汇集数据后进入网络。

三维数字孪生模拟采煤机、刮板输送机、液压支架组成的三机系统，用于预演割煤、运输、移架及设备联动。实际协同中，采煤机的位置、速度和截割深度传给输送机及支架，输送机依落煤量调速，支架依位置移架和支护。

井下设备、供电及排水数据回传地面，操作人员据实时数据进行远程控制。皮带监测以图像识别发现损伤并分级告警，检修人员按等级维护。现场监测汇集顶板离层、瓦斯、风速、一氧化碳和人员位置；5台巡检机器人采集图像、声音、红外热像与温度等数据。

据汇编，项目由矿业集团与当地通信运营商、网络设备企业及煤炭科研院所共同建设，共形成14类21个应用场景。除采掘和运输外，远程操控还延伸到供电、排水和提升：变电所智能保护器把电流、电压等数据传到地面，工作人员可远程调整停送电状态；水仓、泵房的水位与流量数据回传后，地面可远程开启备用泵、切换排水管路；提升机的位置、速度和钢丝绳张力实时回传，操作人员据此控制加减速和停车。

辅助环节同样接入平台。洗煤厂按市场对煤质的要求，通过网络调整介质密度和选煤设备参数；智能矿灯回传井下画面和人员位置，并支持一键呼救；井下高清视频接入AI视频融合平台，用于检查是否按规程作业、设备是否按期维护；钢丝绳检测系统对损伤作定性、定位和定量判断并生成报告。用电方面，电量数据上传后按小班核算电能，并按比例奖罚到个人；电机车定位系统回传车辆位置和车载画面，供调度人员掌握人员与物料位置。

## 5. 实施效果

汇编描述了综合平台、机器人和三机协同等已投入应用的内容，建设价值以减少人工环节、支持故障预警和降低危险暴露等定性结果为主，未给出可与改造前同口径比较的整体产能、成本或事故率数据。本案据此呈现已使用的能力与工作变化。

## 6. 分析与启示

**本书分析：**井下生产的数字模型、装备联动、监测与人员处置共同承担任务。增加智力服务时，可以利用原平台记录辅助核对和组织维护依据，是否进入设备执行则须另作工程验证。5台机器人投入并不能单独证明全部巡检质量或整体经济收益。

从场景清单看，项目的重点不在单个设备，而在把分散的数据汇到同一平台后，由地面人员承接判断和处置：远程操控、视频合规检查和分级告警，最终都落到调度、检修或安全管理人员的动作上。评价这类建设，可以追踪告警是否在规定时间内被处理、远程操作是否减少了井下暴露时间，以及电量核算与个人奖罚是否被一线接受。

汇编所列经济价值和社会价值均为定性表述，提高产能、降低成本和减少事故损失没有给出测算口径。其他矿井借鉴时，宜先确认自身网络条件、设备接口和安全规程是否允许远程控制，再选择少数场景试点，并在改造前留存同口径的产量、工时和故障记录，以便事后比较。
