# J01 基金公司AI研发培训

<a id="c-07-f01"></a>

**阶段：局部使用。**

据 Datawhale《FDE案例100》NO.7（第67-75页）整理。一家基金公司的研发人员各用各的AI编程工具，企业希望形成团队统一做法。第三方实施者把培训放进真实需求，与团队共同约定需求文档的写法和各角色分工，并分期让业务、产品人员参与。实施者称团队工具和协作方式开始统一，但没有可对外披露的投入回报数据。这说明从个人提效走向团队能力，需要共同的协作载体和角色约定。
