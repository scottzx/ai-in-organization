# F12 交个朋友虚拟IP内容生产

[下册索引](../README.md) · [本行业索引](README.md) · [上册研究报告](../../上册-研究报告/README.md)

本篇场景

## 1. 企业介绍

本案例是交个朋友的电商团队在虚拟IP内容生产中的应用。团队以内容支持带货，已有自有虚拟IP和编排平台，视频既包含AI生成内容，也包含真实拍摄。

## 2. 业务背景与改造目标

团队要把编导对视频的判断转为可重复的制作过程：拆解镜头、画面、声音和需求，选择模型处理适合的步骤，再形成内容。

虚拟IP最终服务商品销售。内容制作费用与业务销售规模分别反映生产投入和经营结果，需要按各自范围记录。

## 3. 面临的问题

### 内容拆解与共同标签

AI第一次打出的标签不能直接作为共同标准。编导需要讨论哪些标签正确、哪些内容值得保留，以及哪些步骤适合哪类模型，先统一人的概念。

### 虚拟IP运营与销售

虚拟IP视频由生成内容和实拍共同组成，业务最终面向带货。团队谈到的生成费用与销售规模，分别对应制作动作和整项业务，不能使用同一个结果口径。

## 4. 解决方案与实施过程

### 内容拆解与共同标签

<a id="s-22-f01"></a>

**阶段：局部使用。**

团队将视频拆成镜头、画面、声音和需求等要素，判断要保留的内容及各步骤所用模型，把分析结果沉淀下来。AI先标注，编导共同讨论和校准标签，再将新的规则交回工具重新标注。AI承担重复拆解和生成，团队承担规范与选用判断。

### 虚拟IP运营与销售

<a id="s-22-f02"></a>

**阶段：局部使用。**

团队用自有虚拟IP与编排平台开展内容业务，短视频部分由AI生成，部分结合真实拍摄。内容制作与销售运营按这两类素材共同展开。

## 5. 实施效果

### 内容拆解与共同标签

访谈介绍了标签校准、模型选择和编排过程，表明共同标准已进入局部制作。研究依据为访谈音频，结果按受访团队描述的制作过程记录。

### 虚拟IP运营与销售

受访者称所述虚拟IP业务形成了可观的销售规模；该说法仅见短视频及转述，没有官方披露，本书不采用具体金额，也不能独立归为AI新增收入或利润。单次生成价格较低，也只说明其中一个制作动作的费用，应与实拍、编导、审核、分发和运营投入分别理解。

## 6. 分析与启示

**本书分析：**重复制作需要先统一标签与判断尺度，再让工具按共同规则处理。编导校准既是质量工作，也是把个人经验转为团队标准的过程。

评价虚拟IP应沿合格内容进入销售的过程观察。生成费用、内容质量、平台流量和成交是不同结果，IP、账号与视频也分别是不同对象；共同标准与人工持续校准应进入完整投入。
