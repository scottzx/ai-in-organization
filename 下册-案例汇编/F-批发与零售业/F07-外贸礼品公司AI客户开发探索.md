# F07 外贸礼品公司AI客户开发探索

## 1. 企业介绍

本案例是一家十几人的外贸礼品公司，由第三方实施团队协助整理资料与开发工具。企业积累了图片、模板和客户资料，项目将本地框架与任务包放入客户环境中测试。

## 2. 业务背景与改造目标

项目希望让散落资料能在业务需要时被找到和理解，并逐步形成企业能够使用的资料资产。实施过程同时包含本地环境适配、任务执行和客户反馈。

持续试用中还出现了一个小任务：弄清图片里角标尺的来源和刻度含义。它作为一次资料理解演示单独记录。

## 3. 面临的问题

### 本地资料工具与任务测试

图片、模板和客户资料已经积累，实际工作时却常找不到。工具还要进入客户本地环境：双方环境不一致，业务人员只能用碎片时间配合，使开发、适配和测试彼此牵连。

### 角标尺资料理解

团队遇到一张含角标尺的图片，需要查清标尺从哪里来、刻度表示什么。这个问题要求寻找线索并理解图片资料。

## 4. 解决方案与实施过程

### 本地资料工具与任务测试

<a id="c-11-f01"></a>

**阶段：试点。**

实施者把本地框架和任务包放入客户环境，让AI运行，客户测试后回传日志，双方据此继续适配。资料留在客户环境中，AI既参与开发，也参与任务执行。

### 角标尺资料理解

<a id="c-11-f02"></a>

**阶段：演示。**

在持续试用中，团队让AI查找图片中角标尺的线索并理解刻度。受访者把这次现场任务作为资料理解的具体示例。

## 5. 实施效果

### 本地资料工具与任务测试

受访者明确首阶段尚未完成，客户侧AI累计约40小时运行包含开发与执行。这个时长是项目投入，不能记作40小时人工节省；资料资产系统仍在交付过程中。

### 角标尺资料理解

受访者称AI约10分钟找到角标尺来源和刻度含义。老板原先估计自己可能需要一两天，这一人工时间是预估，结果按单次演示记录，不换算为企业全年节时。

## 6. 分析与启示

**一芥分析：**资料工具要先适应真实工作环境，再通过测试反馈修正。AI参与开发降低了部分制作门槛，环境适配与业务人员配合仍属于交付投入；资料留在本地的做法只描述部署方式。

角标尺任务说明单次资料理解能够提供帮助。项目整体价值应在资料能否稳定检索、客户能否实际使用及维护中检查，并将单次演示与系统交付分开评价。
