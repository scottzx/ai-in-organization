# F01 面向东南亚的服装跨境电商业务协同

<a id="c-22-f01"></a>

**阶段：已使用。**

据 Datawhale《FDE案例100》NO.22（第215-224页）整理。一支面向东南亚的服装跨境电商团队，起初只想打通两个系统，调研后发现物流照片信息靠人工录入、补货单也要手工生成。实施团队用中转数据库同步数据，AI识别物流照片后经人工核对回填，补货沿用企业原有公式、确认后生成订单；据实施者称这部分已投入使用。

<a id="c-22-f02"></a>

**阶段：阶段未明。**

客户还提出库存不足时联动调整广告投放，但实际自动控制到什么程度，来源没有说清。这个例子支持本书的顺序判断：先让资料可靠进入系统，再谈跨业务联动。
