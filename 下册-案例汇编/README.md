现有62个阅读入口：54个行业与待定案例入口、1项跨行业方法、7项原型或演示参考，共101个场景与证据片段。入口数不等于独立公司数，也不等于成功交付数。同一来源涉及不同客户时分别成篇，身份不足的材料保留边界。

行业顺序按GB/T 4754—2017门类组织；仅设有材料的门类，主营活动不足以确认的另列待定。编号前的字母表示行业门类，不表示案例质量或成熟度。
