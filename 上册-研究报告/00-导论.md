# 导论　从业务全貌到数智化经营

一芥智能研究院｜《企业数智化转型研究报告》上册｜初稿 v11.0｜2026年10月17日修订

[上册索引](README.md) · [全书首页](../README.md)

研究团队近期走访中看到，部分企业已经用多种SaaS和定制系统覆盖业务，另一些企业仍主要通过Excel传递记录。基础不同，经营者却遇到了相近的困境：想知道一个项目是否签约、是否具备排产条件、生产到哪一步、应收与实收分别是多少，仍要逐个找销售、生产和财务负责人询问。

业务已经留下数字记录，全貌却要靠人临时拼接。合同、生产和资金各有记录，经营者还需要核实它们是否对应同一项目、反映哪个时间点，以及哪些状态已经确认。一次询问能够补齐当下的答案，下一次变化后又要重新查找。要判断交期为什么受影响、哪项承诺需要调整，企业还得把分散事实接起来，追查原因，并组织后续行动。

本报告从这一经营困境出发，研究企业怎样形成可信记录、可靠衔接与分析行动的能力，智力服务能够承接哪些任务，以及流程和组织怎样随之调整。这些内部能力，也为未来组织之间更快、更可靠的协作准备基础。

<a id="section-0-1"></a>
## 0.1 本报告要回答什么问题

企业数智化的经营价值，可以从数字化、网络化、智能化三项特征理解。数字化使设备、物料等物理状态，以及需求、合同、承诺和任务等业务事实，形成可核对、可更新的记录。Excel本身已经具有数字记录属性，进一步要看内容是否对应真实业务，来源、时间和版本能否辨认。使用业务系统的企业，同样需要检查这些条件。

网络化使分散记录和工作能够可靠接续。系统连接之外，同一项目还需要共同标识、状态口径、更新时间、访问权限和接手责任，变化才能进入相关岗位的安排。智能化则利用这些依据发现偏差、比较原因假设与行动选项，支持经营取舍、执行和结果复核。看清状态是起点，判断为什么受阻、怎样改进以及改后是否有效，才使信息进入经营。

三项特征相互支撑，企业可以围绕一个具体问题并行补齐。智力服务为此提供了新的参与方式：协助建造应用与工具，协调传递资料与任务，分析推理异常、原因和选择。局部建设和试验的门槛有机会降低，依靠人工中转的等待可以减少，从发现问题到检验行动的周期也可能缩短。能否形成经营改善，要看真实业务中的采用与结果。

这些作用需要落实为有边界的任务。负责人交给服务明确目标、获准依据、工具、权限和交付要求，服务推进工作并交出产物，由接收者判断和继续使用。服务参与建设、推理或获准执行，任务中的需求确认、专业判断、重要承诺和经营取舍仍须明确责任。

上册据此提出共同问题：**企业怎样借助智力服务补齐数智化经营能力，让任务改善进入完整业务结果，并使有效方法在组织中持续积累？** 第一章详细解释三项特征、三类作用与任务承接机制，后续章节沿业务和组织检验它们怎样发挥作用。

<a id="section-0-2"></a>
## 0.2 上册怎样逐层展开

三项特征说明需要形成什么能力，具体改造还要有业务标准：哪些事实值得记录，哪些工作必须连接，分析应服务什么结果。华为公开资料中的端到端流程及管理机制，为这些问题提供了参照。MTL、LTC、IPD、ITR分别围绕市场、交易、产品和客户问题处理组织工作，各有完整结果，又相互提供依据、能力和反馈。沿这些业务线，可以检查跨职能配合、关键产物、控制点与结果责任，来源范围见[第三章的方法说明](03-单点提效为何未传导到整体交付.md#section-3-1)。各章具体高标准动作、诊断与人机安排，是本报告面向一般企业的应用整理。

第一章建立能力与任务的共同起点，说明服务怎样接受委托、执行、交付，以及怎样判断任务改造的价值。第二至第五章分别展开四条业务线：MTL形成销售能够接手的有效线索；LTC把机会转为可兑现的合同、履约与回款；IPD形成经验证、可销售交付并获得支持的产品能力；ITR追到客户问题确认解决。各章从现状和业务差距，推导目标、举措及人的关键节点。

第六章把四条业务线放回同一业务全貌，检查状态与依据能否核对、跨线偏差能否分析，以及共同决定怎样进入执行并返回结果。第七章研究建造、执行、判断、管理和决策的职责分工，进一步讨论能力怎样根据运行反馈持续优化。第八章用于实施，按业务价值与依赖组合试点，比较完整投入，决定扩展、调整或停止。结语再由企业内部能力，展望组织内外按任务开展协作的条件。

<a id="section-0-3"></a>
## 0.3 从业务差距推导举措的研究方法

研究先选择能够追踪的客户、项目、产品、合同或问题，明确应取得什么结果，再核实当前怎样开展工作。对照高标准动作，检查哪些事实、判断、产物或交接没有做实，以及后果怎样传到下一环节。书中的典型问题用于引导诊断，是否存在、影响多大，要由本企业记录确认。

找到差距后，再推导改进目标并拆成具体举措：谁做什么，形成什么，交给谁。先讲清业务做法，再判断哪一项建设、协调、分析或执行任务适合交给智力服务，需要补齐哪些资料、工具、权限和验收条件。人的判断与异常接手沿任务落实，产物还要追踪到下一环节的实际采用。

检验时既看质量、采用和业务结果，也核算准备、建设、执行、判断、交接、返工与维护的完整投入。局部节时是否减少了整体等待，释放的容量是否被有效使用，需要分别观察。有效反馈进入新的方法和安排后，还要用后续相近任务检验持续改善。

<a id="section-0-4"></a>
## 0.4 材料依据与研究判断怎样区分

本报告使用研究团队走访观察、公开资料、具名企业访谈、实施者和经营者自述，以及试点、需求讨论和演示。开篇困境属于近期走访观察，用于提出研究问题；具体企业的基础仍按实际工作诊断。正文分别保留来源性质、实施阶段和效果口径：材料怎样取得，工作走到哪一步，数字覆盖什么任务、对象与时期。准备节时、制作费用、收入与利润分别表述。

来源事实、作者分析、组织设计与未来展望各有归属。下册案例支撑相应局部实践；五类角色的完整组织形态、人员迁移、智力飞轮与未来跨组织协作，属于需要继续验证的研究方向。上下册共用稳定案例编号，上册按问题引用场景，下册集中展开主体和过程；[证据台账](附录A-证据台账.md)、[案例引用索引](附录B-案例引用索引.md)及各篇来源定位，供读者回查依据。

<a id="section-0-5"></a>
## 0.5 怎样阅读与使用这份报告

经营者可以先用第一章理解能力与任务，再带着一项真实业务阅读第二至第五章，查找最早受阻的环节。问题跨越多条业务线时，继续看第六章；需要调整能力建设、专业判断和管理职责时，再看第七章。第八章帮助把候选举措变成可以验收、核算和决定去留的试点。

业务负责人和实施人员可以从相关章节进入，沿下册案例回查资料、产物、采用条件和实际阶段。术语与知识网络的补充说明见[附录C](附录C-术语辨析表.md)和[附录D](附录D-知识网络建设细节.md)。阅读最终落到本轮行动：改善什么，由谁承接和判断，结果交给谁，再用真实运行决定下一步。
