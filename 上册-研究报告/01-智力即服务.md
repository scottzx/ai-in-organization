# 第一章　智力即服务：企业获得执行能力的新方式

## 1.1 企业完成工作的方式正在变化

销售拜访客户前，需要了解业务背景和历史沟通；技术人员收到需求后，需要准备解决思路；方案对外之前，还要核实产品能力、报价与交期。企业一直通过岗位分工和协作完成这些工作，资料搜集、判断、制作与审核也一直可以拆成具体任务。

AI带来的变化，首先发生在任务怎样完成：已有资料可以交给AI辅助整理，已确认需求可以用于起草方案，初步想法可以借助工具形成原型。业务人员因此有机会减少重复准备，取得原先需要更多制作或协调才能获得的产物。这里改变的是部分工作的承接方式，岗位职责、业务目标和结果责任仍需明确。

同一产物在不同阶段的用途也不同。原型可以帮助客户讨论需求，进入工程实现后还要处理交互、异常、测试和运行；方案初稿可以帮助内部讨论，向客户提出承诺前还要审核。判断一项能力是否可用，要先知道当前任务需要交出什么、交给谁使用。

制造业的发展为理解这种变化提供了一个参照。手工制造已有分工，机械化、规模化与智能化生产进一步改变了任务的承接和组织方式。执行能力增强后，工序、质量检查和上下游容量也需要相应调整。智力服务同样需要研究执行能力与组织安排怎样配合：更多任务可以交给AI，企业就要重新判断如何分工、怎样交接和验收。

<a id="section-1-2"></a>
## 1.2 智力即服务带来了哪些新选择

白惠天、袁晓辉、司晓在《Token经济》的公开导言中，用“智力即服务”（intelligence as a service）概括部分智力工作可以按服务调用、计量和组合的变化。本报告采用这一概念，依据为[出版社公开导言与试读](https://detail.youzan.com/show/goods?alias=278xflkurbbdrv7&from_source=gbox_seo)，不将其表述为对全书的完整研读。

对企业而言，调用能力意味着可以重新安排一段工作。例如，销售提供有效资料和沟通目的，AI整理客户简报；技术人员判断方案取舍，工具帮助制作材料；明确的计算按既定规则处理，再由授权人员批准对外条件。各段采用什么方式，要结合质量、协调和核验投入判断。

经过验证的方法还可以复用。相近任务不必每次从头说明全部要求，可以逐步保留提示要求、资料查找步骤、模板和审核经验。复用时仍要带入当前客户、版本与约束，确认原有方法是否适用。能力可调用，不代表所有任务已经能够可靠委托。

> **案例小贴士｜前道准备改变，专业服务继续承接。** [CGL招聘实践](../下册-案例汇编/L-租赁与商务服务业/L05-CGL招聘AI协作.md#s-20-f01)描述了局部使用：顾问提供岗位需求，工具参与人才地图、简历筛选、触达与意向确认，感兴趣的候选人再交顾问联系。这提供了按具体任务安排执行的参照；后续候选质量与顾问交付仍需观察，不能用前道处理数量代替最终结果。

<a id="section-1-3"></a>
## 1.3 新能力怎样转化为业务价值

采用新能力前，业务负责人需要说明希望改善什么。销售可能需要扩大有效线索、提高阶段转化，客服可能需要更及时地解决问题，采购可能需要减少错买。目标明确后，才容易判断资料整理、内容生成或系统操作是否解决了实际差距。

围绕目标，还要明确任务输入、产物、使用者与验收标准。客户资料不完整，简报就需要标出待核实项；需求尚未确认，方案只能保留相应假设；生成的待办无人接手，就需要先落实分工。资料、判断与交接条件共同决定技术帮助能走到哪一步。

技术可以辅助查找依据、起草和比对，系统可以保存版本、状态与责任记录。业务人员仍要核实重要事实、确认产物可用，并按权限作出承诺与决定。企业据此观察准备是否更充分、错误是否减少、下游是否能够继续工作，再追踪相应业务结果。第二章将把这套分析落到销售岗位的具体目标与举措。

<a id="section-1-4"></a>
## 1.4 怎样判断改进是否值得

评价改进，先确认交付范围和质量要求，再比较前后投入与效果。人工准备、执行、核验和返工要计入，工具、系统、外部服务及维护费用也要计入；一次性建设与持续运行分别记录，共用投入按明确口径分摊。生成便宜只是其中一段的变化。

工时用于观察人的投入，Token（词元）可以观察按词元计费的模型调用投入，两者不能直接相加。核算时，工时按相应人时成本计价，模型调用按适用计费方式记录；订阅、转写、存储及其他服务费用另列。企业原本也有软件和设备等投入，AI应用的完整成本不能只概括为人工与词元两个科目。

> **案例小贴士｜制作费用之后，还有合格交付。** [森马电商](../下册-案例汇编/F-批发与零售业/F02-森马电商AI转型.md#s-01-f01)受访者以原每款约2800元、现在十几元生成十几张图说明制作费用变化，同时保留了领标修补、面料和版型检查等后续工作。这些数字对应制作环节。比较完整成本，还需把审图、修补、人员及配套投入归到符合上架要求的图片上。

成本替代应在同等交付范围、质量与合格数量下比较，数量不同时可观察单位合格交付成本。覆盖增加、响应改善或释放承接容量，也可能有业务价值，应另行记录。节省工时是否减少支出，过程改善是否带来签约、收入或利润变化，都需要相应依据。

<a id="section-1-5"></a>
## 1.5 本章小结

智力即服务使部分工作有了新的承接方式。企业可以从业务目标识别任务，选择适合的执行安排，明确产物、条件与责任，再用实际采用、合格交付和完整投入判断改进。调用量与生成数量提供过程信息，业务价值还要沿后续工作观察。

这些判断需要落到具体岗位。第二章以市场与客户开发为例，先梳理职责与工作流程，再分析有效线索形成与销售实际接手，逐项提出业务做法，判断数字化与AI能够提供哪些帮助。
