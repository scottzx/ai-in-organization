# 第一章　智力即服务：一个供给侧的变化

## 1.1 从"拥有能力"到"调用能力"

设想一家企业只有客户所在城市和采购总额。它能够把客户分成几个大类，安排大致不同的服务，却很难知道某个客户最近为什么减少购买、正在比较什么产品。后来，订单、服务记录和行为信息逐渐可获得，企业才有条件围绕更具体的客户情况采取行动。

这一轮AI变化可以沿着类似关系理解，但多了一层。过去，企业把许多工作归到一个岗位，由这个岗位上的人完成或协调；现在，资料理解、初稿制作、代码生成这类工作，可以通过调用获得执行能力。企业不必先"拥有"这段能力，就可以先"调用"它。

白惠天、袁晓辉、司晓在《Token经济》的公开导言中，用"智力即服务（intelligence as a service）"概括这种变化：部分智力工作能够脱离某个具体人的工时安排，以服务形式被调用、计量和组合。本报告引用这一概念，依据为出版社公开导言与试读，不将其表述为对全书的完整研读。[出版社公开内容](https://detail.youzan.com/show/goods?alias=278xflkurbbdrv7&from_source=gbox_seo)

回到企业，这表现为几件具体的事：一名销售准备客户拜访，可以先调用服务整理已有资料；一名产品人员需要讨论需求，可以借助工具制作原型；一名工程师处理开发任务，可以让AI参与编码与文档。企业取得的，开始包括**完成具体工作的部分能力**，而不只是意见与建议。

<a id="section-1-2"></a>
## 1.2 为什么这是一次要素供给的变化

如果只把上述现象当作"工具变快了"，管理动作会落在培训和推广上。本报告认为它更接近一次**要素供给方式的变化**，理由分别来自三个分析传统。

<a id="section-1-2-1"></a>
### 1.2.1 分工与协调成本：承接者可以被重新安排

斯密在《国富论》第一篇第一章说明，分工通过提高熟练程度、减少工作切换和改进机器来提高生产率。但分工不是免费的：科斯在《企业的性质》中提出，一项工作由组织内部完成还是交由外部完成，取决于**交易成本**的比较；威廉姆森进一步指出，资产专用性、不确定性与交易频率会影响这个比较。

把这个框架放到今天：一段工作过去必须在组织内部、由具备相应技能的人完成，因为对外委托的协调成本太高。当"调用一段智力服务"的成本下降到某个水平以下，**这项工作的承接者就有了新的选项**——由人做、由程序做、由模型做，或者分段由不同承接者做。

这解释了本报告的第一层问题：为什么任务可以被切出来。它也预告了第二层问题：切出来以后交给谁，取决于协调成本，而不是取决于技术是否可行。

下册[L05 CGL招聘AI协作][L05]展示了一条前道流程：顾问提供岗位需求，工具参与人才地图、简历筛选和意向确认，再把感兴趣的候选人交给顾问。变化落在具体工作上，而不只是给招聘顾问增加一个聊天账号。

<a id="section-1-2-2"></a>
### 1.2.2 有限理性与程序化决策：可委托的范围由"能否被说明和验收"决定

西蒙指出，人的理性受信息与计算能力约束，因此组织中的决策可以分为**程序化**与**非程序化**两类：前者可以被规则、流程或程序处理，后者需要在具体情境中判断。

这个区分给出一条比"AI能做什么"更有用的判据：**一段工作能否被交出去，取决于它能否被说明、以及产物能否被验收。** 能说清输入、产物和验收标准的，可以被交给服务或程序执行；依赖现场判断、关系与承诺的，仍然需要人。

这条判据解释了企业实际遇到的分野。同一项工作在不同阶段可以采用不同分工：原型阶段关注是否把需求讲清，工程阶段要处理完整交互、异常、测试与运行。一次原型足够支持客户讨论，并不代表已经足够承担生产交付。

它也是本报告采用"人主导、AI辅助"取向的理论依据：关系、承诺和重要判断由人承担；资料搜集、记录整理与会前准备，可以另行评估。

<a id="section-1-2-3"></a>
### 1.2.3 知识的非竞争性：可复用、可组合、可按量调用

罗默说明，想法是非竞争性要素：一份方法被一个人使用，不妨碍另一个人同时使用，而且可以被反复组合，从而带来收益递增。

服务的可调用性正建立在这个性质上：同一段能力可以被多次调用，每次调用带上不同的输入和上下文。这既解释了它为什么可以像服务一样被计量，也解释了为什么计量的对象是"调用"而不是"人"。

但也正因为可复用，它的计量容易误导：一次调用产生了产物，不等于这次调用产生了价值。下一节说明计量的起点应该放在哪里。

<a id="section-1-3"></a>
## 1.3 计量从哪里开始：Token作为投入的观察单位

服务可以按量使用，企业便有机会把调用投入观察到具体任务。Token是目前这一层最直接的计量单位：**它描述的是投入。**

但调用量与价值之间，还隔着质量、采用和业务结果。同样一份报告，生成得更长不代表更有用；同样一个程序，消耗更少调用量也不代表更可靠。企业需要先说明这项任务应该交出什么，再比较不同完成方式所需的投入。

下册[F02 森马电商AI转型][F02]保留了一个有用的过程：商品素材生成提速之后，员工仍要修正错误领标、检查面料、版型和细节。若生成的图片不能上架，或者要经过大量修正，一次生成的低价格就没有说明合格交付的成本。

因此，一次合格任务的投入至少包括：服务调用、人工准备、核验、返工和必要的维护。本报告**不以Token数量给企业排效率，也不把调用费用当作AI应用的全部成本**。

计量的意义在于支持比较：同一质量要求下，哪些安排更划算；同一投入下，哪些任务更值得做。这就引出本报告贯穿全书的一条线索——**以投入规模论强度，以单位产出论效率**。

<a id="section-1-4"></a>
## 1.4 变的与不变的：执行可以分段，责任不能转移

传统组织的工作原本就能拆分。一个人每天有许多待办，也会并行承担几项工作。岗位把相近职责归到某个人或某类人，任务再沿着职责分配、跟进和交接。**拆分之后，组织中的最小执行与协同单位通常仍是人。**

本轮变化扩展的是**承接者的范围**：拆出的一小段工作，可以获得新的执行承接者。资料搜集可以先交给AI，选题方向由人判断；订单信息可以由工具整理，装配人员据此执行；模型提取图纸信息之后，成本计算还可以进入企业的规则程序。

曾鸣在2026年9月3日发布的《张小珺商业访谈录》第153期中，讨论了由岗位组织转向以任务为基本单元的组织设想，为这一问题提供了思想参照。本报告据此继续研究当前企业怎样定义、分配和交接任务。相关段落在约01:10—01:12。[节目来源](https://www.xiaoyuzhoufm.com/episode/6a97f287f03e74ee6b03ea5b)

这种组织设想不证明岗位已经消失。企业仍要有人决定目标、确认标准、接手异常，并对交付负责。**执行可以选择，责任不能转移。** 新的执行选择越多，这些责任越需要被说明——这正是第二章要处理的问题。

<a id="section-1-5"></a>
## 1.5 结论与事实边界

本章可以确认的是三件事：

1. 部分智力工作已经可以脱离具体人的工时安排，以服务形式被调用、计量和组合；
2. 这改变的是"承接者"的选择范围，不是"是否需要有人负责"；
3. 计量的第一层是投入（Token），不是价值。

**事实边界**：本章引用《Token经济》的依据为出版社公开导言与试读；曾鸣的访谈采用释义；[F02 森马电商AI转型][F02]为具名企业访谈与岗位操作讲述；[L05 CGL招聘AI协作][L05]为第三方实施者访谈自述。
