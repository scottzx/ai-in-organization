## 两册怎样共用案例

上册按问题选择同一案例中的不同场景，下册按主体集中呈现过程。编号保持一致，重复引用不重复计算企业或效果。具体来源、阶段和限制见下册各篇及[案例来源索引](../索引/案例来源索引.json)。

本书的精细化管理与精益经营、持续组织循环、组织智力循环和智力飞轮，均按正文所述工作含义使用；技术机会、设计目标与实际验证分别表达。
