# 上册　研究报告

一芥智能研究院｜《企业数智化转型研究报告》上册｜初稿 v9.0｜2026年10月16日修订

[全书首页](../README.md) · [下册案例汇编](../下册-案例汇编/README.md) · [按问题阅读](../索引/阅读路径.md)

本册从智力服务带来的执行选择出发，将MTL、LTC、IPD、ITR分别展开为四章，再讨论四条流程共同运行的智力飞轮与实施决策。四条流程相互协作并形成反馈：市场提供线索，产品能力支撑销售承诺与交付，客户需求和使用问题进入产品判断。借鉴制造业的生产组织经验，重点分析任务分工、跨部门衔接与结果责任；技术随具体需要引入，效果结合实际采用、交付与完整投入判断。各章独立成篇，章内另设小节索引。
