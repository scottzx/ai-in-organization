# 上册　研究报告

一芥智能研究院｜《企业数智化转型研究报告》上册｜初稿 v11.0｜2026年10月17日修订

[全书首页](../README.md) · [下册案例汇编](../下册-案例汇编/README.md) · [按问题阅读](../索引/阅读路径.md)

本册直接从企业数字化建设出发：过去为什么做，建设到了什么程度，遇到了哪些问题，今天为什么进一步推进数智化，以及具体怎样做。第一章解释智力成为服务的新变化及其价值，再用有边界的任务说明怎样承接。第二至第五章借鉴华为的端到端流程及管理机制，诊断MTL、LTC、IPD、ITR的现状、高标准动作、差距与后果，提出总体思路，再推导子目标和具体举措。第六章研究各条线怎样形成共同经营结果，提出跨线取舍与协同行动；第七章据此安排组织职责和持续优化，第八章验证实施与投入。结语展望组织内外协作的未来变化，讨论客户与链主牵引的供应链改造、渐进建设与提前准备，再引出计划编写的中册行业方案。
