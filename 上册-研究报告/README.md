# 上册　研究报告

[全书首页](../README.md) · [中册行业解决方案](../中册-行业解决方案/README.md) · [下册案例汇编](../下册-案例汇编/README.md) · [按问题阅读](../索引/阅读路径.md)

本册直接从企业数字化建设出发：过去为什么做，建设到了什么程度，遇到了哪些问题，今天为什么进一步推进数智化，以及具体怎样做。第一章先解释智力服务的成本、响应与持续性特点，再用有边界的任务说明承接和价值检验，最后展开服务参与三化建设与运行的机制。第二章以MTL展开这些机制，后续沿LTC、IPD、ITR继续研究。第二至第五章借鉴华为的端到端流程及管理机制，从业务现状与问题进入分析，提出整体处理思路，明确数智化方案与建设交付物，再简述各业务场景怎样使用。第六章研究各条线怎样形成共同经营结果，提出跨线取舍与协同行动；第七章据此安排组织职责和持续优化，第八章验证实施与投入。结语从供给侧现实价值转向需求侧购买方式的变化，借Muse说明新的购买入口，展望企业响应、履约与供应链协作面临的要求，再衔接中册行业方案。
