# 中册编写配置

本目录保存公开书稿的章节范围、补充来源元数据和新增案例条目，供编辑脚本复用。企业过程见[下册](../../../下册-案例汇编/README.md)，行业正文见[中册](../../../中册-行业解决方案/README.md)。来源的公开链接、页码和校验值用于回查，原PDF全文按原发布者链接查阅。

维护对应配置后，在仓库根目录按需运行：

```sh
python3 scripts/merge-middle-cases.py
python3 scripts/build-middle-sources.py
python3 scripts/build-middle-index.py
python3 scripts/validate.py
python3 scripts/validate-middle.py
python3 scripts/build-site.py
```

新增案例使用稳定编号，已经登记的条目有差异时合并脚本会停止，以免覆盖现有记录。补充书目只列既有行业资料库之外的来源。核验输出保存在已忽略的本地研究记录目录。

原图已经随书稿提供。需要重新渲染时，按行业资料索引取得相同版本的本地PDF，安装Poppler后运行 `python3 scripts/extract-middle-figures.py`；该步骤不属于日常网页发布。逐图来源与版本记录见[中册原图来源](../../../中册-行业解决方案/assets/README.md)。

图示范围与已经核查的元素边界维护在[图示裁切规则](图示裁切规则.json)。配置包括主资料库和补充餐饮报告的源PDF路径、SHA256、物理页码、印刷页码、图题、裁切框及必须内嵌的行业章。运行 `python3 scripts/extract-middle-figures.py --trim-margins` 重建裁切图；也可用 `--sources A11 B02 --industries 工程机械` 只选部分图，用 `--force` 强制重建。日常网页发布直接使用仓库中已核验的图片，无须本地PDF或PDF解析依赖。

脚本先核对源PDF版本，再完整渲染源页并按确认框取图，不以最大内嵌图片推定架构边界。新增图先用PDF元素定位，再对整页与候选裁片逐图检查；图题、来源、必要脚注和水印一起保留。裁切收益同时看横向和纵向留白，接近满版的图保留整页。裁切框外为其他正文的页面，完整PDF页及印刷页定位保留在相邻图注中。正文用Markdown图片语法内嵌，再以同一图片地址包一层链接，使图片直接显示且可点击放大；来源PDF链接作为相邻图注补充。

全部65篇行业与专业业务方案采用五节正文，依次为行业特点与业务目标、总体架构、主要数字化模块、智力服务、适用结论，章末独立列“参考资料”。结构与写法见[行业章节模板](../../../templates/行业解决方案章节模板.md)，本册目录版本为v0.5，行业章版本按编写范围逐篇登记。参考条目沿用上册的连续编号、机构、题名链接、年份、页码及引用范围；企业实践在对应模块就近引用。共用实施方法集中于上册第八章，中册工作表用于行业方案选用与能力对照。

行业边界和旧页到新篇的对应见[行业分篇调整](行业分篇调整.json)。`编写范围.json`是行业章目录依据；旧合并页保留为分篇入口，不计入行业章，网站导航及相邻章节按正式篇目组织。图示用途随独立行业迁移，公共或跨行业图保留其实际适用范围。
