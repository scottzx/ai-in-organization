# AI进入组织：从智力服务到精益经营

**一芥智能研究院**｜研究报告与企业案例汇编｜两册初稿 v7.0｜2026年10月10日

智力成为可调用的服务，使更小的工作获得新的执行承接者。企业有机会把任务、交接、验收和责任管理得更精细，再把这种能力用于减少浪费、改善客户交付。

上册按问题论证，下册按行业、公司或项目集中呈现案例，面向企业老板、业务负责人和参与组织改造的实践者。

## 怎样持续更新

正文采用Markdown，便于逐章修订、独立分享与持续扩充。上册引用下册的稳定编号；同一公司的新场景优先补入原篇，新主体按行业增加文件，再同步行业、下册和问题索引。

修改记录保存在[CHANGELOG](CHANGELOG.md)，补充方式见[编写与贡献约定](CONTRIBUTING.md)。本次版本为依据已确认第七版大纲写成的第一轮正文，后续继续补充持续采用、核验投入与完整业务结果。

## 来源与使用

企业案例主要依据公开资料、受访者自述和演示整理。正文区分来源事实、一芥分析与待验证判断，保留已使用、试点、原型、设想等阶段。单点节时、销售额、毛利额和净利润分别表述；本书未对案例效果作独立审计或完整事实核验。
