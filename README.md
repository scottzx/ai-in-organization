# 企业数智化转型研究报告

**从智力服务到精益经营**

**一芥智能研究院**｜研究报告与企业案例汇编｜上册初稿 v9.0·下册初稿 v8.0｜2026年10月17日修订

智力成为可调用的服务，使具体工作有了新的承接方式。本报告从业务目标出发，分析岗位任务、跨岗位流程与持续运行安排，判断数字化与AI怎样帮助企业改善工作表现，以及如何用实际交付、完整投入与业务结果验证改进。

上册按问题论证，下册按行业、公司或项目集中呈现案例，面向企业老板、业务负责人和参与组织改造的实践者。

业务章节按“问题—分析—目标与多项举措”展开：先用高标准动作诊断执行缺口及后果，再说明数字临时工怎样承接任务，人把牢哪些关键节点与产物。第二章为六个目标、十八项举措，第三章为五个目标、十五项举措，第四章为五个目标、十四项举措，第五章为五个目标、十三项举措；第六章进一步按五个目标、十五项举措，检查四条业务线的融合与持续改进。

上册从执行能力的新选择出发，第二至五章分别展开**MTL、LTC、IPD、ITR**四条业务流程。第二章分析怎样从市场形成销售实际接手且可跟进的有效线索；第三章分析怎样把线索转为商机、合同、履约验收与回款；第四章分析需求怎样经过取舍、跨职能开发与验证，形成能够销售、交付和支持的产品；第五章分析客户问题怎样得到受理、处理、验证与确认。四条流程相互协作并传递反馈，产品能力支撑客户承诺，客户机会与使用问题又进入产品判断。第六章沿四条业务线的交汇，连接可用产物、共同取舍、资源承接与方法复用，让反馈改变下一轮实际工作，用业务结果检验决策、试错、复制和切换是否加快；第七章说明怎样选择、实施和验证。各层都观察实际采用、合格交付、完整投入与相应业务结果。

上册共引用下册 **33 个案例、41 处**；未被引用的案例及其可支持的主张见[附录B 案例引用索引](上册-研究报告/附录B-案例引用索引.md)。下册现有62个阅读入口：54个行业与待定案例入口、1项跨行业方法、7项原型或演示参考，共101个场景与证据片段。入口数不等于独立公司数，也不等于成功交付数。

## 怎样持续更新

正文采用Markdown，便于逐章修订、独立分享与持续扩充。上册引用下册的稳定编号；同一公司的新场景优先补入原篇，新主体按行业增加文件，再同步行业、下册和问题索引。

修改记录保存在[CHANGELOG](CHANGELOG.md)，补充方式见[编写与贡献约定](CONTRIBUTING.md)。暂不纳入正文的素材保存在[草稿箱](草稿箱/README.md)。上册为初稿 v9.0，下册保持初稿 v8.0；下册62篇案例已按[统一七节模板](templates/企业案例模板.md)重写，依次呈现主体、业务背景、问题、实施过程、效果、分析与来源。

## 来源与使用

企业案例主要依据公开资料、受访者自述和演示整理。正文区分来源事实、一芥分析与待验证判断，保留已使用、试点、原型、设想等阶段。单点节时、销售额、毛利额和净利润分别表述；本书未对案例效果作独立审计或完整事实核验。

本书只作经营管理分析与案例整理，不构成法律、财务、税务、医疗或其他专业意见；涉及具体业务操作时，请咨询相应执业者。各案例在实施阶段、效果口径与资料来源中说明适用范围。
