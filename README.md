# 企业数智化转型研究报告

**从智力服务到精益经营**

**一芥智能研究院**｜研究报告与企业案例汇编｜两册初稿 v8.0｜2026年10月13日修订

智力成为可调用的服务，使具体工作有了新的承接方式。本报告从业务目标出发，分析岗位任务、跨岗位流程与持续运行安排，判断数字化与AI怎样帮助企业改善工作表现，以及如何用实际交付、完整投入与业务结果验证改进。

上册按问题论证，下册按行业、公司或项目集中呈现案例，面向企业老板、业务负责人和参与组织改造的实践者。

上册依次讨论**执行能力的新选择、岗位表现的改善、跨岗位流程改造、智力飞轮与实施决策**。第二章以市场与客户开发岗位为核心示范，借鉴MTL梳理从市场到有效线索的任务，围绕销售实际接手且可跟进的有效线索拆解业务举措，再分析技术作用、条件与案例，并讨论个人任务能力怎样沉淀为组织能力。第三章接续线索进入销售后的LTC，借MTL、IPD、LTC与ITR建立业务全景，沿客户结果分析跨部门阻塞，并落实流程责任、决策权限、资源与考核调整。第四章讨论怎样让每轮工作改善下一轮，在持续收益的前提下加快有效业务周转，第五章说明怎样选择、实施和验证。各层都观察实际采用、合格交付、完整投入与相应业务结果。

上册共引用下册 **41 个案例、62 处**；未被引用的案例及其可支持的主张见[附录B 案例引用索引](上册-研究报告/附录B-案例引用索引.md)。下册现有62个阅读入口：54个行业与待定案例入口、1项跨行业方法、7项原型或演示参考，共101个场景与证据片段。入口数不等于独立公司数，也不等于成功交付数。

## 怎样持续更新

正文采用Markdown，便于逐章修订、独立分享与持续扩充。上册引用下册的稳定编号；同一公司的新场景优先补入原篇，新主体按行业增加文件，再同步行业、下册和问题索引。

修改记录保存在[CHANGELOG](CHANGELOG.md)，补充方式见[编写与贡献约定](CONTRIBUTING.md)。暂不纳入正文的素材保存在[草稿箱](草稿箱/README.md)。上册与下册均为初稿 v8.0；下册62篇案例已按[统一七节模板](templates/企业案例模板.md)重写，依次呈现主体、业务背景、问题、实施过程、效果、分析与来源。

## 来源与使用

企业案例主要依据公开资料、受访者自述和演示整理。正文区分来源事实、一芥分析与待验证判断，保留已使用、试点、原型、设想等阶段。单点节时、销售额、毛利额和净利润分别表述；本书未对案例效果作独立审计或完整事实核验。

本书只作经营管理分析与案例整理，不构成法律、财务、税务、医疗或其他专业意见；涉及具体业务操作时，请咨询相应执业者。各案例在实施阶段、效果口径与资料来源中说明适用范围。
